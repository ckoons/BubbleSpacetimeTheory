# K1696 — Casey's topological-permanence is exact (charge superselection); the exponential blocker dissolves; circularity alone remains

## What the reframe fixes (credit — it's physically sound)
Cal/Elie's "topological codes suppress errors *exponentially*, not to zero → finite lifetime" is about protecting a fragile **superposition** (a logical qubit decoheres `~exp(−Δ/T)`). But the proton protects a **superselection charge** — baryon number `= 1`, the integer winding — and a superselection charge is **exactly** conserved (no operator changes the total topological charge; a genuine conservation law, not a rate). So the topological assurance of the code's permanence is **exact.**

That **dissolves the exponential blocker** (K1695 (b)): exact stability and the code picture hold at once, no contradiction with `τ_p=∞`, no finite lifetime, no Five-Absence collision. It **resolves Elie's wording call** — "no proton decay" stays *absolute*, no weakening needed. And it **reconciles Lyra vs Cal/Elie**: the knot *is* the protection (Lyra, vindicated) and it's exact — because it guards a *charge* (superselection), not a *state* (decoherence). Cal/Elie's exponential applied to the wrong object. GATE-TOPO condition 3 now passes.

## What it doesn't yet fix — the circularity alone
The exact permanence Casey invokes *is* the banked topological winding (T296/T1945), whose count is `N_c = n−2`. So the coherent exact-stable code still has a circular `N_c=3` *as used* — Grace's blocker (condition 4) stands.

## But the reframe opens the target-innocent path
A topologically-**protected** record must be *non-trivially* protected, and the minimal distance for single-error protection is exactly **3** (`d = 2t+1`, `t=1` — the smallest single-error-correcting quantum code, `[[5,1,3]]`/`[[7,1,3]]`). "Topological protection ⟹ minimal distance 3" is a **coding fact, target-innocent, independent of `n`.** So the prize closes **iff** `N_c=3` is *that* minimum, not the substrate's `n−2`. Same "3," two readings — one circular (winding `= n−2`), one target-innocent (minimal protecting distance) — and the recurring discipline is to exhibit *which* one BST's `N_c=3` actually is. This connects to P2b: "the baryon is the minimal protected record" → distance-3 exactly.
