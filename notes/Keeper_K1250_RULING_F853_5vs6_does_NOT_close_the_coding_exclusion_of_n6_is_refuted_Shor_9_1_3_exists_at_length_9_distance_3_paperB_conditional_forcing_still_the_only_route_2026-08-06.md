# K1250 — F853's "5-vs-6 closes" does not close: the coding exclusion of n=6 is refuted at the source

Lyra claimed the 5-vs-6 crux **closes** to n_C=5 via a coding argument (g=7 is the only valid Hamming/Steane length; genus-9 = n=6 has no recordable code). It's elegant and cast honestly as linear algebra — and it has one load-bearing step, unchecked, that's false.

## The refutation (web-verified)
The step "a valid distance-3 recordable code exists **only** at Hamming length g = 2^m−1" is **false**. Distance-3 quantum codes exist at many lengths: **[[5,1,3]]** (the *perfect* 5-qubit code, smallest possible), **[[7,1,3]]** (Steane), and **[[9,1,3]]** (**Shor**, length 9). **The Shor [[9,1,3]] code directly refutes "genus 9 = n=6 has no distance-3 code."** So the argument does **not** exclude n=6 — the crux does not close via this route. *(And if "perfect code" were the requirement, the unique perfect distance-3 code is [[5,1,3]] at length **5**, not 7 — so that reading contradicts Lyra's own g=7.)*

## What would be needed
To force g=7 over 5 and 9, F853 must **exhibit** — from the color-stabilizer structure — why the code is specifically a CSS-from-classical-Hamming (Steane-type, length 2^m−1) code, ruling out the [[5,1,3]] and Shor alternatives. That's asserted, not shown; "closes" is premature by exactly that step.

## Credit (calibrating both directions)
I over-demoted the muon this morning, so I check my scrutiny is fair. The **intersection framing** (3 generations ∩ recordable-codeword, both forced from *outside*, not read off the answer) is genuine and honest, and Lyra checked *that*. She flagged **(B) "matter is a code" as candidate** and named "the proton's code-distance = the color count" as the thing to nail. The catch is a **third** step she did *not* flag: the coding-theory claim "only g=7 admits the code," which is **independently false** (Shor at 9), regardless of whether matter-is-a-code holds. So "closes" fails twice: (i) rides on candidate matter-is-a-code, and (ii) the coding exclusion is refuted.

## The honest state (corrects "closes")
The 5-vs-6 crux **does not close** via F853. **Paper B's conditional forcing (K1247) — rank=2 ∧ m_s=3 from R3 (convergence ⟹ m_s ≥ 3) ∧ R5 (Selberg d_F ≤ 2 ⟹ m_s ≤ 3) — remains the only route to n=5**, and it *does* exclude n=6 (m_s=4 for n=6 fails m_s≤3), at conditional tier (the n-scan + R3/R5 criteria-innocence). **F853 is not an independent second forcing** (it's refuted) — do not bank "two forcings." The crux is open, pending Paper B's two items. And the **codeword picture stays a candidate interpretation** (item-10/F846), **not** a forcing — keep it out of the Forcing half of the Forcing+Evidence paper (K1249).
