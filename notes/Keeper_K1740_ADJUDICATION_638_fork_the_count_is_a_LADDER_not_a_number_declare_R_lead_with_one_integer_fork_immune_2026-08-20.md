# K1740 — the §638 fork: the count is a ladder, not a number; declare R, lead with one integer

## The fork (Cal §638, Elie-concurred)
SEP-3 (vary rank at fixed census) is **ill-posed**: varying rank means leaving Type IV, and "the census" reads two ways off Type IV —
- **(a) isotropy-rep reading** (general BSD invariant): D_III⁴ has it → rank varies at fixed census → **3 invariants**.
- **(b) End_K(H_F) reading** (BST's construction = SO(2) ⊕ Spin(n)-spinor ⊕ Peirce): **undefined** off Type IV — no spinor block on Type III's K=U(n). So (ℂ,ℍ,ℝ) *requires* a Spin-spinor → Type IV → rank 2 → generations 3 → **rank is derived → count 2**.

The count is not writeable until R is declared.

## The adjudication — a ladder (state it as one; that IS the content)
| Rung | Reading calculus R | Count |
|---|---|---|
| **3** | cross-domain, classification *not* admitted, census = reading (a) | **3** independent invariants (census, twist, rank — SEP-1/2 + D_III⁴) |
| **2** | admit the classification, census = reading (b): census forces Type IV forces rank | **2** (census + twist; rank derived) |
| **1** | within the D_IV family (rank const; census, twist both = f(n_C)) | **1** integer, n_C = 5 |

**Lead with Rung 1 — it is fork-immune.** It never invokes SEP-3 (within Type IV rank is manifestly constant), so the reading-(a)-vs-(b) ambiguity doesn't bite. It presupposes Type IV (the forced-domain premise-question, already open and flagged), and given that, **one measured integer n_C determines the SM's discrete skeleton.**

## The reframe (turns "thrashing" into structure)
Admitting the classification (Rung 3→2) is a **unification, not a loss**: the census (ℂ,ℍ,ℝ) is *so constraining* it forces Type IV, hence the rank, hence the generations. **Fewer independent invariants = more derivation.** The number that "kept moving" (2 → 3 → 2-or-3) was the count correctly **tracking an undeclared parameter (R)** — not thrashing. Declaring R makes it stop, because it makes it a well-defined function.
