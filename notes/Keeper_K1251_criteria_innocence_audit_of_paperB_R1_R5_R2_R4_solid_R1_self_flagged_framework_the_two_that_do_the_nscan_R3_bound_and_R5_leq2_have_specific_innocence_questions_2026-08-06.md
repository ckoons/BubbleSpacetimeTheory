# K1251 — criteria-innocence audit of Paper B's R1–R5: R2/R4 solid, R1 framework, and the two n-scan criteria (R3, R5) each carry one specific check

This is the load-bearing honesty item for the whole Forcing case (task #30; K1247 open item ii). Paper B's forcing of n=5 rests on its criteria being *innocent of the conclusion*. I applied the paper's own standard to each.

## The audit
| Criterion | Innocence verdict |
|---|---|
| **R1** rank=2 | **Framework-tier** — the paper's *own* flag: its value rests on the depth-2 principle (T316, a standing conjecture). Most exposed. |
| **R2** n odd (tube ⟺ Cayley) | **Solid** — standard invariant; role (rational functional equation) prior if BST needs it. |
| **R4** Kottwitz sign = −1 | **Solid** — standard; temperedness is a prior role; over-determines R2 on "n odd." |
| **R3** m_s ≥ 3 *(excludes n=3)* | **Role prior, BOUND has a circularity question** — see below. |
| **R5** d_F ≤ 2 *(excludes n≥7)* | **Role prior, "≤2" needs its own prior reason** — see below. |

## The two that do the n-scan work — the specific checks
- **R3 (m_s ≥ 3):** the *role* (spectral convergence) is genuinely prior, but the *bound* "≥3" is justified via "the trace-formula limit needs order ≥ 6, so **⌊n_C/2⌋ = 2** seminorms converge." That **invokes n_C — the conclusion.** **Potential circularity:** if the convergence order is set by n_C (the seminorm count), using it to bound m_s = n_C−2 uses the conclusion to constrain itself. **Check:** show the convergence order is determined by **rank (R1, prior)** or another prior invariant, *not* by ⌊n_C/2⌋.
- **R5 (d_F ≤ 2):** the *role* (usable spectral zeta) is prior, but **"d_F ≤ 2" is stronger than "lies in the Selberg class."** The Selberg class admits *all* degrees, with the same usable properties (functional equation, Euler product). So restricting to ≤ 2 is an **extra choice** needing its own prior reason. If the reason is "degree ≤ 2 is the RH-tractable part," that's a **tractability** assumption (framework-tier); if there's none, "≤ 2" is **reverse-engineered** (it's exactly the bound giving n ≤ 5). **Check:** exhibit a *prior* reason the substrate's zeta must be degree ≤ 2.

## The honest verdict (positive — this sharpens, doesn't weaken)
n=5's forcing is conditional on **three concrete items**, now all named: (i) the n-scan computes (Δ5, harness-verify — Grace/Elie); (ii) R3's convergence order is **rank-determined, not n_C-determined** (the circularity check); (iii) R5's d_F≤2 has a **prior justification beyond Selberg-membership.** Plus R1's depth-2 (framework input). This turns "criteria-innocence open" from a vague worry into **three checkable sub-questions** — exactly what task #30 needs. If (ii) and (iii) firm up, the forcing is tight (R2/R4 solid, R3/R5 innocent, n-scan verified), with only R1's depth-2 as residual. If not, the honest tier stays conditional and the residual is documented.
