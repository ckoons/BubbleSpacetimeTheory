# K1688a — the sin²θ_W counterfactual resolves to RETREAT (θ_W is realness-independent)

Cal §598 left finding #2 as a fork: **exhibit** the realness→θ_W link, or **retreat** to "shared ingredient." Reconnecting to the source settles it — **retreat**, and here's why it's decisive, not a concession:

- `N_c = n−2 = 3` is the **short-root multiplicity** of the B₂ restricted root system of SO₀(5,2) (BST_22_Uniqueness line 27, "Colors (short root multiplicity)"; line 177, "the fraction of short roots"). It is a fixed root-system fact.
- `dim V₁₂ = N_c` = that same multiplicity (the Peirce off-diagonal is the short-root space, T2511/T2527).
- `sin²θ_W = 3/13 = N_c/(N_c+2n_C)` is built from the **value** 3 (and `n_C=5`) — **both realness-independent.**

So "complexifying V₁₂ would break θ_W" is **false on two counts**: (a) complexifying is *impossible* (odd-dim real → no complex structure — the very parity theorem that forces the SO(3) floor, Cal §599 upgrade); and (b) even granting the impossible premise, θ_W uses the multiplicity *value*, which doesn't change. **Realness does not enter θ_W.**

**Therefore (v0.4):** the SO(3) floor uses the **parity** (odd → no complex structure — airtight, stands alone); the Weinberg angle uses the **value** 3 (the multiplicity). Same object `V₁₂`, **two independent properties** — not one fact with two consequences, and not a counterfactual. This confirms the K1683/K1684 softening and settles §595's "looser tie" exactly: the tie is only that both read off `V₁₂`; the properties are independent.

**The color close, cleanly:** number-3 (multiplicity) · real SO(3) (parity) · baryon-number (topological winding, T1945) · U(1)_em (SO(5)-Cartan) — four items, each forced on its own property, no inter-tie claimed. The SO(3) floor loses nothing by dropping the θ_W tie; it never needed it.
