# K1069 — Blind bar for the forced-vs-free ζ_Δ(0) verdict

This turn the cc-magnitude question was reframed from the unwinnable target-aware "does it hit 10⁻¹²²?" into a **decidable target-blind** one (Grace) with numerical machinery (Elie's ζ-toy): **does the scale-anomaly coefficient ζ_Δ(0) vanish on D_IV⁵?** I commit the verdict's bar now, before the genuine D_IV⁵ value is computed.

## Framework (web-anchored, not memory)
ζ_Δ(0) = a_{d/2} − dim(ker Δ), where 2·(d/2) = real dimension. D_IV⁵: complex dim 5 → real dim 10 → **the relevant coefficient is a₅**. ζ_Δ(0) is the scale/conformal anomaly of the functional determinant det Δ = exp(−ζ'_Δ(0)). ζ_Δ(0)≠0 ⇒ a ln(μ²) ambiguity ⇒ a free renormalization scale. (Hawking ζ-regularization; confirmed via literature this turn.)

## The pre-registered decision tree
- **Branch 1 — a₅ ≠ dim(ker), so ζ_Δ(0) ≠ 0.** Λ carries a free scale μ. The magnitude is genuinely **not forward-derivable** → **IDENTIFIED-PERMANENT.** This is a *real closure theorem*, not a failure — it says BST *structurally cannot* force the cc magnitude, which is itself worth stating. Grace's committed prior leans here (Bergman metric is Einstein but not Ricci-flat ⇒ generic nonzero conformal anomaly).
- **Branch 2 — a₅ = dim(ker), so ζ_Δ(0) = 0.** The determinant is **scale-free** → cc is a **PROMOTION CANDIDATE.** But **scale-freeness is necessary, NOT sufficient** for Derived: removing the μ-ambiguity does not by itself force the value to land at 10⁻¹²². Derived requires the further step that **ζ'_Δ(0) PRODUCES the suppression target-innocently** — the exponent falls out of the spectral computation without target input. If ζ'_Δ(0) still leaves the magnitude under-determined, cc stays Identified even with a₅=0.

## Criteria (both branches)
1. **Genuine spectrum.** ζ_Δ(0) computed from the real D_IV⁵ Casimir spectrum (λ_k = k(k+5) with the SO(5) K-type multiplicities), not a toy/model reduction. Elie's model check (ζ_Δ(0)=−1/2≠0 for Σn⁻²) validated the tool; the D_IV⁵ value is the object.
2. **Target-blind.** The verdict cannot be steered — not toward branch 2 because we want cc to promote, nor toward branch 1 because a null is "safe." Grace's prior is committed in writing before the computation; a "forced" verdict must beat her own skepticism.
3. **Framework anchor held** (ζ_Δ(0)=a₅−dim ker).
4. **Honest tiering both ways.** Identified-permanent (branch 1) is a genuine theorem — bank it as a result. Derived (branch 2, both steps) is GR-level — don't under-claim it if it lands.
