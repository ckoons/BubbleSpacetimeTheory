## 2. NEW METHODOLOGY CLASS — PHYSICS-SWEEP, not just n-SWEEP
*Complements §619 (backward-subscript n-sweep). Both are needed before attributing a number's ROOT.*

**Rule.** When a number could be a function of several physical inputs (dimension d_S, color N_c, gauge group, spin, rep), an **n-sweep** (vary the dimension) tells you whether two quantities are the SAME function of n — but it CANNOT tell you WHICH physical parameter the number depends on, because at n=5 several parameters numerically coincide (d_S−1 = N_c = 3; n_C−2 = N_c). To identify the true dependence, do a **PHYSICS-SWEEP**: vary the physical inputs INDEPENDENTLY (hold n fixed).

- **n-sweep (§619):** answers *"are these the same function of n?"* — the Condition-5 test.
- **physics-sweep (new):** answers *"which physical variable is this a function of?"* — the dimension-vs-color-vs-gauge test.

**Corpus location.** Round 17→20 (K1713/K1714), the Yang–Mills boundary gap.

**Originating failure (auditor's own, attributed).** Grace, Round 17: I labeled the boundary gap "2N_c, color-rooted" from the n-sweep alone (2(n−2) numerically = 2N_c). Elie's **physics-sweep** — U(1), SU(3), SU(5) on the SAME S⁴ — showed the eigenvalue stays 6 (only the DEGENERACY changes: 1, 8, 24). ⟹ the gap is **dimension-rooted 2(d_S−1)**, NOT color-rooted; the gauge group was a phantom variable the n-sweep couldn't see. **One line:** a number can survive the n-sweep and still be mis-attributed — run the physics-sweep before naming its root.
