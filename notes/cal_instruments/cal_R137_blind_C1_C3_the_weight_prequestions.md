## C3 — the sign fork

H6. **Not a fork. A typing error, and resolving it is not preference.** A probability is the expectation of an EFFECT — a bounded operator 0 ≤ E ≤ 1 — in a state (Born, T754). ⟨|z|²⟩ is that. The Hardy-over-Bergman ratio R(j,k) = (5)_{j+k}(7/2)_j / [(5/2)_{j+k}(1)_j] is a ratio of two NORMALISATIONS of the same function in two different Hilbert spaces. It is not an operator on either space, it has no complement, it is not bounded by 1 — R grows without bound — and the map it is built from, A²_5 → H², is not a contraction between those spaces, so what it measures is not a loss. **A Bergman-normalised high-winding word has a LARGE Hardy norm: the number says the boundary amplifies it, not that the boundary rejects it.** Calling 1 − 1/R "the probability the push fails" types a normalisation mismatch as a probability. Both readings may be reported; only one is a candidate for a probability, and that is a statement about types, not about which sounds physical.
H7. **What would decide it operationally — and the answer the corpus already has.** A commitment probability needs three things: a state, an effect, and an outcome that something in the dictionary does DIFFERENTLY. The corpus has the first two by identification and lacks the third: Round 134's E3 (Elie 5736) showed the write chain is identical to twenty digits with and without the carried winding, and nothing in the dictionary branches on push success or failure. **A quantity on which nothing depends has no direction to argue about.** So: "commitment" is not defined sharply enough to have a sign, and the reason is a result the corpus already banked. The fork is not resolved by choosing a reading; it is dissolved by observing that neither reading has a consequence.

Consequence for the round's framing: the honest headline is not "two readings disagree in sign" but **"the push cost is a coordinate on the weight axis (Elie 5743), it vanishes where the record lives, and no dictionary transition depends on it — so it prices nothing."** That is Keeper's own September-4 gap ("the push to the boundary is r → 1... not derived; asked") and it is still the open question.
