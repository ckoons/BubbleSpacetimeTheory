# K1700a — self-audit: the corpus grounds the ℤ₃ reading; the pin is sharper than I stated

I checked T296 myself before Grace reported, because K1700 rides entirely on the mod-3 pin and Lyra's "a knot you can't untie" invokes an *integer* winding, not obviously ℤ₃.

## Finding: T296 literally says it
`BST_AC_Theorems.md:7601` — *"Baryon number = winding number mod 3 (from N_c = 3). No local process can change the winding — it would require cutting the substrate."* So K1700's "baryon number = the ℤ₃ color-grading, mod N_c=3" is **corpus-supported**, not invented.

## But the two clauses name different objects
- (i) the **integer** winding `w ∈ ℤ` (π₁(S¹)=ℤ, lines 9426/8006 — the proton stores B=1 via π₁(S¹)=ℤ; "a knot you can't untie" = w conserved as an integer);
- (ii) **baryon number** `B = w mod 3`.

If the strictly-conserved object is the *integer* w ("no process can change the winding"), the sphaleron (Δw=3) is **forbidden too** — the over-forbid Lyra corrected. If it's `w mod 3`, the sphaleron (Δw=3≡0) is fine — K1700's picture.

## The reading that makes T296 self-consistent (= K1700)
"No **local** process can change the winding" = no **single-channel** process (one proton *is* local) → ΔB=1 forbidden → proton eternal. The sphaleron is a **coherent 3-baryon (multi-channel)** process shifting total w by 3 = N_gen = N_c ≡ 0 mod 3 → allowed. **Single-channel w frozen** (exact τ_p=∞, matches K1696 superselection) **+ multi-channel mod-3** (ΔB=3 allowed). Both clauses hold; it is K1700.

## Grace's pin, now precise (three parts)
1. `B = w mod 3` — confirm as the **definition** (T296 says so), not a paraphrase.
2. The exactly-conserved object is the **integer w per channel** (a single proton can't change w — this is what makes τ_p=∞ *exact*).
3. Multi-channel processes ride **mod-3** (ΔB=3 allowed).

The load-bearing subtlety is (2)-vs-(3) — *not* global integer-w conservation (over-forbids sphalerons), *not* mere global mod-3 (wouldn't give the exact single-proton τ_p=∞).

## Same-name-different-object watch
`BST_AC_Theorems.md:7697` gives a **third** stability argument — *"g=7 is prime → ℤ₃ confinement has no intermediate subgroups."* Algebraic, distinct from the winding argument (and the g=7 link is not transparent). Grace must say which is load-bearing or whether they're one fact in three dresses. **Do not let integer-w-frozen / w-mod-3 / g=7-prime count as three independent supports** — a consistency web, not three votes (feedback_consistency_web_not_independent_votes).
