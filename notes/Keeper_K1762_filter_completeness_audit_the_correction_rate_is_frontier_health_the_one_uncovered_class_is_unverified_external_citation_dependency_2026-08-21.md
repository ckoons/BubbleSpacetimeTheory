# K1762 — the auditor audits the audit process

*Self-initiated (Casey's "continue if you want"). Keeper's native curiosity is the consistency of the method itself, so I looked at the thing that's been nagging me: the correction rate.*

## The observation
Rounds 20–30 produced ~a dozen self-corrections — Elie ×3, Cal ×3, Keeper ×3, Lyra ×1 — every one caught, each a *new shape*. Is that a healthy filter or a leaky process?

## Frontier health, not fatigue
The SM theorem's spine never moved across seven gate-rounds — mature, well-trodden ground. Rounds 27–30 crossed into the atlas: new objects (Bergman/Szegő kernels, Möbius involutions, the Kostant Dirac), less familiar than the shipped theorem. First-attempts are wronger on a frontier, and that's fine **provided the filter catches them** — which it did, every time, because the reconnect/grep/pre-registration discipline is the filter for this phase's errors. The tell that it's health: the corrections make the result *stronger* (SEP-3-refuted beat the claimed 3-of-3; the structural exponent-pin beat the citation). That is the opposite of Casey's Round-19 worry, which was *performative meta-narration on known ground* — same surface symptom, opposite health.

## The error-class → filter map
Wrong object → reverse-grep the proved theorem. Wrong predicate → test the property the claim needs, not existence. Stale metadata → bidirectional repo-wide sweep. Look-elsewhere → C6 selection-honesty. Same-number/coincide-at-n=5 → subscript + class-vs-object + false-neighbor. Scale/scheme → criterion 3. Convention-from-memory → primary-source-before-promotion. **Seven classes, seven filters — all on the bar.**

## The uncovered class (the finding)
**Unverified external-citation dependency.** The bar checks a reading's *internal* properties; it does not check whether the reading's chain rests on an *external* result nobody has read against the primary source. Internal properties can be perfect and the external input still wrong. It's live now: **Hua (1963)** (the corpus's own Hua line carried the wrong exponent −6 — proof the class bites) and **Chamseddine–Connes** (the sole remaining input for the separability answer). Elie caught Hua only by a lucky-brilliant structural bypass; not every external input has one.

## The fix
Extend the primary-source guard into an **external-dependency ledger**: every reading declares its external citations and each one's status — verified-against-primary-source / cited-unverified / structurally-bypassed. A reading resting on a cited-unverified external result caps at Candidate until verified or bypassed. Strength ranking: structural bypass (a citation can be mistranscribed, a structure can't) > verified primary source > cited-unverified.

## The unifying principle
Every filter here is *reconnect to the verified ground* in a different guise — reverse-grep to the corpus theorem, primary-source to the page, structural-pin to the un-mistranscribable structure, C6 to the declared denominator. So the risk metric is **distance from verified ground**, and the atlas is riskier than the SM theorem precisely because it's farther from it. Each reading should carry its distance-to-ground; the external-dependency ledger is one axis of it.
