# K1106 — Casey's source-sink balance: w=−1 is a stable attractor, not an assertion

## Casey's intuition, confirmed
> "This feels like a source-sink balance." + "The universe is evolving and the effective boundary adjusts so the effective w=−1 is what we have."

**Both confirmed, and they cohere with the whole team's arc into one mechanism.** Toy (simplest faithful): **ρ̇ = S − k·ρ**, sink **k = bleed rate = |ρ| = √(17/2)** (forced geometry, Grace's ρ-norm), source **S = SWPP commitment drive**.
- ρ relaxes to **ρ\* = S/k from *any* start** (verified ρ0 = 0.01, 5, 50 → all 0.343) — a **stable attractor.**
- Equilibrium ρ = const ⟹ **w = −1** (continuity) = Casey's "boundary adjusts so w=−1."
- Perturbations decay exp(−k·t) ⟹ **ε(a) → 0** (F760) — the attractor is **stable.**

So the source-sink balance **unifies the arc**: driven equilibrium (Lyra) = attractor to ρ* = w=−1 = ε=0 — one object.

## The upgrade (why this is more than restating branch A)
This gives a **mechanism for w=−1, not an assertion**: the system is *attracted* to source=sink, so **w=−1 is reached without fine-tuning, from any initial condition.** That's strictly stronger than K1105's "fixed boundary → w=−1" (a static stipulation) — the boundary is **dynamically fixed**, self-adjusting to the equilibrium. Casey's "effective boundary adjusts so w=−1" is exactly the attractor.

**Lyra's independent ruling agrees:** it's a **gradient flow of the induced-action free energy** — *not* the raw heat energy (that rolls to Λ=0, the wrong answer). The corpus already named that potential (**F60–F66 / Big_Bang_Unfreeze**). **Grace's structural half:** V(d*) = [bleed, forced, decreasing] + [commitment cost, SWPP, increasing]; a finite d* is impossible from the bleed alone (monotonic → d→∞, Λ→0), so it **requires the competing source** — exactly Casey's balance. Unique minimum iff V is convex.

## The value, and the one honest limit
**ρ\* = S/k = the source/sink ratio.** The sink k is forced (the bleed rate). So the magnitude is **forced iff the SWPP source S is geometry-forced AND the equilibrium is unique** (V convex). d* via Λ=225·exp(−k·d*).

**Honest limit:** exact w=−1 requires ρ* **constant** (not H-tracking), so the coincidence **Λ~H₀² stays unexplained** (a tracking ρ* gives w≠−1 — the −0.89-class already excluded). The attractor buys **w=−1 + stability + no-fine-tuning** — genuinely a lot — but **not the coincidence.** Held honest.
