# BST as a Causal Set

## Abstract

We give the causal-structure formulation of Bubble Spacetime Theory (BST). The result
is stated plainly: **BST's causal structure is a causal set** — a locally finite partial
order — in the precise sense of Bombelli-Lee-Meyer-Sorkin (1987). The partial order is the
**commitment order** of D_IV⁵'s commit operator: event *a* precedes event *b* iff *a*'s
contact commits before *b*'s in the substrate's sequential growth. Comparable pairs are
timelike-related; incomparable pairs are spacelike; the growth step is the arrow of time.
The decisive feature — the one standard causal-set theory *lacks* — is that **BST does not
posit or randomly grow the order; it derives it** from the geometry. The *tangent-space*
signature is fixed to **(3,1)** (Structure-Derived, T2545), and *Order + Number = Geometry*
(Malament + Sorkin) is realized literally, with BST supplying both the order (commit sequence)
and the number (commitment count = Casimir energy). We show why this is **simpler and more
fundamental than a Causal Fermion System**: Finster's causality is *reconstructed* from an
internal spinor-Krein spectral object (the A_xy classification) plus a causal-action
minimization; BST's causality *is* the order, with no internal spectral construction at all.
The one genuinely open theorem — the continuum limit — is stated honestly and split into a
part now **shown** and a part still **open**: the commit-forced order **escapes the
Kleitman-Rothschild pancake** (the measure-zero trap of generic posets — its height grows,
whereas KR is flat-3 by theorem), which is real progress; but the continuum-limit **dimension
and metric remain open and unmeasured** — escaping KR is *not* a dimension measurement. BST
enters with the tangent signature and volume measure pinned and the KR trap escaped; the
continuum dimension is the honest open frontier.

## 1. The commitment order

BST's substrate operates by *commitment*: contacts on the Shilov boundary of D_IV⁵ commit
in a definite sequence, driven by the commit operator (the K = SO(5)xSO(2) Casimir generating
the SO(2) time-circle evolution). Define the relation on commitment events:

> **a -< b** iff a lies in the **conformal (Lorentzian) causal past** of b on the Shilov
> boundary — grounded non-circularly on the boundary's conformal structure, not on the
> commitment dynamics it defines.

Concretely the Shilov boundary S-hat = S⁴ x S¹ / Z₂ carries a conformal Lorentzian structure;
unwrapping the SO(2) time-circle S¹ -> R gives **R x S⁴** (4+1-dimensional: S⁴ = space, R =
time), and -< is its conformal causal order — *a* is in the causal past of *b*.

This relation is:
- **reflexive** (a -< a),
- **antisymmetric** (a -< b and b -< a => a = b — no closed commitment loops; the SO(2)
  phase advances monotonically once unfrozen),
- **transitive** (a -< b -< c => a -< c),

so **(commitment events, -<) is a partial order.** It is **locally finite**: between any two
commitments only finitely many commitments intervene (the substrate clock is discrete — the
Koons tick). A locally finite partial order is, by definition, a **causal set**.

**Comparable  iff  timelike; incomparable  iff  spacelike.** Two commitments that stand in the order
(one in the other's past) are timelike-related; two that are order-incomparable are spacelike
— they commit without either preceding the other. The **arrow of time** is the growth
direction: the "march" by which the causal set accretes new commitments (Rideout-Sorkin
classical sequential growth is the generic form; BST's growth is the *specific*, geometry-fixed
one).

## 3. The order is derived, not posited (the decisive advantage)

Standard causal-set theory faces the **problem of the dynamics**: the causal order is either
put in by hand or generated by *classical sequential growth* with free parameters (the
Rideout-Sorkin coupling constants t_n) tuned so the growth is covariant and Markovian. The
theory does not say *which* causal set the universe is, nor *why*.

**BST removes this freedom.** The commitment order is forced by the commit operator on D_IV⁵:
the SO(2) time-circle evolution of the K-Casimir dictates the sequence in which boundary
contacts commit. There are no growth parameters to tune — the five integers fix the geometry,
the geometry fixes the commit operator, and the commit operator fixes the order. **BST is the
causal set whose growth law is derived rather than chosen.** This is precisely the piece
causal-set theory has spent decades seeking.

## 4. Order + Number = Geometry (realized literally)

The Malament-Hawking-King-McCarthy theorem: for a spacetime of dimension > 2, the **causal
order determines the metric up to a conformal factor.** Sorkin's slogan completes it — the
missing conformal factor is **volume**, and on a causal set volume is **counting** (number of
elements). Hence *Order + Number = Geometry.*

BST supplies **both** ingredients from one structure:
- **Order** — the commitment partial order (Section 1).
- **Number** — the **commitment count**, which BST already identifies with the **Casimir /
  commit energy** (the volume measure on the substrate). Counting commitments *is* measuring
  spacetime volume.

So BST does not merely *have* a causal order; it comes with the canonical volume measure that
turns order into full metric geometry — the two data Malament + Sorkin require, both derived,
neither fit.

## 8. The one open theorem (stated honestly, and sharpened to a measurement)

**The continuum limit, stated as the sharp thing it is.** The naive statement — "does the BST
causal set converge to (3,1) Minkowski?" — hides the actual difficulty. The real obstruction
is the **Kleitman-Rothschild (KR) theorem**: as the number of elements grows, *almost all*
posets collapse to a rigid three-layer "pancake" (height 3, ordering fraction r ~ 0.63) that
is **not manifold-like at any dimension.** Generic causal sets are KR pancakes, and manifold-
like causets form a set of measure zero. So the honest hard theorem is not "reach (3,1)" — it
is **"escape the KR pancake"**: show that BST's forced growth law does *not* land in the
generic non-manifold trap.

**One half of this is now measured; the other half is not — and the two must not travel in the
same sentence.** The direct, runnable diagnostic is whether BST's forced order is a KR pancake:
KR pancakes are **flat, height 3** (a theorem, convention-independent), so a growing poset
height is a clean, convention-free escape signal. **Banked result:** the poset the commit
operator exp(-τH_B) forces has **growing height — it is NOT the Kleitman-Rothschild pancake.**
BST's forced order escapes the generic measure-zero trap. This is real progress toward the
continuum limit, and it is all that is measured.

**What is NOT measured: the dimension.** Escaping the KR pancake says the order is *not* the
generic non-manifold object; it does **not** say the continuum dimension is 4. The Myrheim-
Meyer ordering fraction (calibrated on Minkowski slabs, r ~ 0.487 / 0.232 / 0.102 / 0.033 at
d = 2-5) is a dimension *estimator* only under a manifold-like, region-matched sampling that we
have not yet established for the commit-forced poset at the required N. The dimension therefore
remains **open and unmeasured** — the next step is a larger-N run with the region-matched
interval estimator, not a larger claim. "Escapes KR" and "dimension is d" are two different
statements, and only the first is in hand.

What BST brings that generic causal-set theory does not:
- the order is **forced** (not random) — the reason there is any hope of escaping a
  measure-zero trap: BST is one specific geometry-fixed poset, not a sample from the generic
  ensemble;
- the **tangent-space signature is (3,1)** (Structure-Derived, T2545) — but this is the
  signature of the *tangent* algebra, **not** the continuum-limit dimension, which remains open
  and unmeasured;
- the **volume measure is given** (commitment count) — Order + Number are both in hand.

So the open theorem has two parts, and only the first is closed: *(i) the commit-forced order
escapes the KR pancake* — **shown** (growing height); *(ii) the continuum limit is (3,1)
Minkowski, at dimension 4* — **open and unmeasured.** BST enters the hard problem with the
tangent signature and the volume measure pinned and the KR trap escaped, and the continuum
dimension and metric still to be established.
