# K1233 — self-catch: the commit F(x) must be indefinite (2,2)/Krein, not a positive projector; the naive candidate is degenerate; the split is achievable; G2 sharpened

On "continue," I stress-tested the candidate construction I handed Lyra in K1232 — before she builds on it. It fails, and the failure is informative.

## The catch (verified in scratchpad)
K1232 offered **"F(x) = the coherent-state / Bergman projector."** That is too naive. A **positive** rank-1 projector P_x makes the product P_x P_y have a **single** nonzero eigenvalue |⟨x|y⟩|² (verified: 1.0, 0.67, 0.21 across separations). With one eigenvalue, Finster's "all |λ_j| **equal** ⟹ spacelike" is **trivially** true for every pair ⟹ **everything is spacelike ⟹ a degenerate, no-arrow-of-time causal structure.** A positive projector cannot be the commit F(x). This also matches Finster's definition directly: F ∈ F must have **≤n positive AND ≤n negative** eigenvalues, and the spin scalar product ≺u|v≻_x = −⟨u|xv⟩ is **indefinite** — a projector has signature (1,0).

## The fix (where BST's indefinite structure lives)
F(x) must carry the **indefinite (Krein) metric**, and BST has exactly this:
- D_IV⁵ = SO₀(5,2)/[SO(5)×SO(2)] sits in a space with the **(5,2)** form;
- item-10's **two committed record-idempotents** with the (2,2) matter/superpartner pairing give **signature (2,2) at spin dimension n = rank = 2** — which is **exactly Elie's G3 candidate.**

So the catch **redirects straight onto the indefinite (2,2) object G3 already names.** The correct candidate: F(x) = the **indefinite** local correlation operator from the occupied K-types with the (5,2)/Krein spin scalar product, signature (2,2), n = 2.

## Achievability confirmed (honest)
A nontrivial causal split **is achievable** from indefinite (2,2) operators — generic ones give products with real, magnitude-**split** eigenvalues (timelike), equal (spacelike), or complex (lightlike). So the framework isn't empty. **But it is not automatic:** a first naive indefinite model (a pure boost) gave all-spacelike. Producing the split requires F(x) built so F(x)F(y) has genuinely split |λ|.

## This sharpens G2
G2 is **not** "is F(x) indefinite" (necessary, easy). It is: **does the specific BST indefinite F(x) produce a product-spectrum whose timelike/spacelike split reproduces the commit-Casimir causal split (K1226)?** That is the real computation — Elie's calculator 5089 fed the **correct (indefinite)** F(x).

## What I own
My K1232 "F(x) = Bergman projector" was too naive (positive ⟹ degenerate). Corrected to **"F(x) = the indefinite (2,2)/Krein local correlation operator, n = rank = 2"** — which unifies with Elie's G3 candidate and the (5,2) signature of D_IV⁵. The candidate **measure ρ** (invariant boundary measure) is unaffected.
