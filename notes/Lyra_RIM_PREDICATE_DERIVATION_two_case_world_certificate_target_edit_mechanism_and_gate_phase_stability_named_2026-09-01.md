# THE RIM PREDICATE, DERIVED

Setting: component R_m of the stranded remnant (link-free — condition (i) of the label);
relabel τ = (r s_M) on R_m; target c* in the gate phase's set (τ ≤ 5 colorings — d_gate's
target, per the seam ruling); rim edges = edges (u, x), u ∈ R_m, x ∉ R_m with x in the contact

Confinement), so τ swaps every u's color to the other of the pair.

## 1. The predicate (rim-local, as the statement demands)

  **ρ(R_m, c*) : for every rim edge (u, x): τ(c*(u)) ≠ c*(x).**

Checkable on Rim(R_m) alone ✓. Where c* agrees with c at both ends (no contact), ρ holds FOR
FREE: τ(c(u)) = (w·c)(u) and c(x) = (w·c)(x) there (x off-patch), and w·c is proper — the
clean-case certificate, per rim edge. So ρ can fail only AT contact, which is why the contact
census enumerates the case world.

## 2. The failure certificate — one equation (derived, both cases)

At a rim edge (u, x), using c*(u) = c(u) on R_m (the target need not be re-imagined on the
remnant — any target differing on link-free R_m is strictly farther there and is dominated;
forcing: the τ-conjugation bookkeeping of the clean case): ρ fails at (u,x) iff

  **c*(x) = τ(c(u))** — the target colors the contact vertex with exactly u's POST-relabel
  color.

- **Type (iii) rim vertex (x ∈ patch):** the word moved x: (w·c)(x) ≠ τ(c(u)) (properness of
  w·c on the edge). So failure requires c*(x) ≠ (w·c)(x) — the target DISAGREES with the

- **Type (ii) rim vertex (x in the target-difference set, off-patch):** (w·c)(x) = c(x), and

## 3. The target-edit mechanism (penalty ≤ |Rim|, proved at the edit level)

Where ρ fails at (u, x): EDIT the target at x: set c*′(x) := (w·c)(x).
- The edited edge is now proper BY w·c's OWN PROPERNESS (both ends carry w·c values:
  u re-dressed to τ(c(u)) = (w·c)(u); x edited to (w·c)(x)). Forcing: nothing about x's other
  neighbors is consulted for THIS edge.
- Each edit changes the disagreement count H(w·c, c*′) by exactly −1 at x relative to the
