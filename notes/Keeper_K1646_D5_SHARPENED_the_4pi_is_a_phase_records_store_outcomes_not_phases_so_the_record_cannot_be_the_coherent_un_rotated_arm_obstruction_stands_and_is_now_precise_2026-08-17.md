# K1646 — D5 sharpened: the 4π is a phase, records store outcomes, so BST's own architecture obstructs the measurement (precisely)

Cal's D5 is the deepest open item in the time program: **can the 4π be observed?** The self-interference argument needs an "un-rotated arm" held coherent while the other copy evolves — but a time generator has no external "still" reference. I reconnected to the corpus to see whether BST already supplies one, and the honest result is a *sharpening*, not a resolution — which is the outcome worth having.

## The natural BST candidate: the record
Principle #16 (K1152) and the Machian/exterior-frame results (K1522) give BST an obvious candidate for the un-rotated arm: **the record.** Matter on the boundary stores committed writes; a record is **irreversible** (T2543 — records don't un-commit), so it "holds still" as a fixed reference while the rest evolves. Seductive — it looks like exactly the external reference D5 wants.

## Why it fails (the disciplined finding)
The 4π is a **relative phase.** exp(2πiJ)|ψ⟩ = −|ψ⟩, and |ψ⟩ and −|ψ⟩ are the **same ray** — no measurement on the state alone distinguishes them (a global phase is unobservable). The −1 is only visible by **coherent interference** against a reference held across the evolution.

But a **record stores an OUTCOME, not a phase.** A committed record is the classical, decohered, definite datum — "which projector fired" — exactly the *"single outcome is a boundary datum"* of Measurement-as-Commitment. A decohered classical record **cannot carry the coherent amplitude** an interference measurement requires. So the record — BST's natural un-rotated arm — is the wrong kind of object: it holds *outcomes* still, not *phases*.

## The obstruction, now precise
So D5 sharpens to: **is there a coherent, 4π-surviving reference for the time generator?** The candidates:
- **a record** — classical/decohered, can't carry the phase; ✗
- **another quantum subsystem** — the superselection issue Cal named, or it reintroduces an external clock; ✗
- **the state alone** — the global phase −1 is unobservable; ✗

There is **no obvious coherent un-rotated arm.** Therefore:
- **T = 4π as a representation fact: BANKED** (unchanged).
- **Its observability: OPEN, and the obstruction is now sharp** — no coherent 4π-surviving reference; and BST's own architecture (records store outcomes, not phases) is *why*.

## Why this is the right outcome (not a disappointment)
This is the anti-pretty-story move: I engaged the corpus's natural resolution (records = the external clock), and the reconnect *caught* that it fails for a precise, statable reason — instead of my banking a seductive "BST records solve the external-clock problem" that a referee (or Cal) would demolish. And it *supports* the Measurement-as-Commitment structure: records are outcomes (boundary data), phases are not stored — the same fact makes the 4π unmeasurable by records. The result stands; the story about measuring it is genuinely obstructed, and now we can say exactly by what.
