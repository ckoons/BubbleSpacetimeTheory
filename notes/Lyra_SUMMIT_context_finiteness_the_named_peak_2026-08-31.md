# THE CONTEXT FINITENESS LEMMA (the named peak)

## 1. The statement to prove (or refute — both are summit outcomes)

**Context Finiteness (target).** There is a FINITE set of abstract contexts — each specified by
BOUNDED data — such that: (i) every stuck insertion configuration in every sphere triangulation
presents exactly one context; (ii) the context determines whether each alphabet letter applies
and its M1 effect (local decidability, measured at 620/620 with zero violations — to become a
consequence, not an input); (iii) the assignment configuration ↦ context is computable from a
bounded neighborhood plus bounded crossing data.

If proved: the three per-context proofs (the foothills) plus soundness constitute completeness,
Gate Existence follows, and the Insertion Theorem closes the classical induction with a small
finite check — human-readable, Lean-friendly. If refuted: the failure names the unbounded
datum, and Route B (Kempe–Wilson saturation) takes the lead with that datum as its first input.

## 2. Why radius-2 neighborhoods CANNOT carry the lemma (the trap, pre-named)

Vertex degrees in general triangulations are unbounded, so radius-2 colored neighborhoods form
an INFINITE family: any enumeration keyed on neighborhoods is dead before it starts, and a
"finite check" claimed over neighborhoods would be the natal-family error at the level of the
theorem itself. The measured 620/620 radius-2 sufficiency is a fact about the MEASURED family —
scaffolding, not the peak.

## 3. The bounded-data route (the credible path up)

What IS bounded, degree-uniformly: (a) the ALPHABET — two letters (identity, triple) mod gauge;
(b) the WALL-CROSSING TYPES at a patch boundary — the transition data is
identity-or-transposition valued (Lemma 1's dichotomy), so crossing types are words in a
bounded alphabet with bounded pattern classes; (c) the LINK STRUCTURE of the hole — five
positions, the τ=6 pattern classes (bridge/gap/Middle-Strict machinery — all finite); (d) the
charge/knot data near the patch — quantized (ω ∈ {0, ±1} per site by the quantization theorem).
**The lemma's shape: prove that (a)–(d) DETERMINE letter applicability and M1 effect — i.e.,
that the unbounded remainder of the neighborhood is gauge/irrelevant.** Elie's enumeration is
already framed this way (bounded data, not neighborhoods — his round-20 note), so the build
itself runs the question as an experiment: a closed bounded-data table exhibits finiteness
constructively; a context that splits on outcome names the missing datum exactly.
