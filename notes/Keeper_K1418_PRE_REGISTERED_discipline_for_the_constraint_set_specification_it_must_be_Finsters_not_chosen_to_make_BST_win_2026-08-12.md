## Why this needs a blind bar (the trap)
The B1 minimum question is "is our configuration the minimizer of Finster's causal action *subject to which constraints*?" — and **the constraint set is now a free choice that determines the answer.** The failure mode is precise and seductive: **pick/tune the constraints so that BST's 215/185 configuration comes out as the minimizer.** This is exactly the target-fit pattern we've retired everywhere else (Wyler's volume-integral, the spectral cap, the ×5) — but *worse*, because a constraint set chosen to make our config win is indistinguishable, after the fact, from Finster's genuine constraints unless you pinned them independently first. **So the constraints must be committed target-innocent, before the check.**

3. **FAIL conditions (any one → reject):**
