# K1166 — item-10 promotion gate (blind pre-commit)

Filed **before** the team's item-10 results land, so a pass can't be retrofitted — the externals-integrity-gate discipline applied to the item-10 frontier.

## Meta-rule
Item 10 promotes to **Derived (QM 10/10)** only when **all** hold: L1 ✓ (already) · **L2 theorem** · L3 ✓-conditional (already) · **L4 theorem** · **Cal's non-anthropic guard passes on both L2 and L4** · **the code-symbol↔fermion-mode identification is rigorous** (same object, not same word). Otherwise → **9 Derived + 1 posit**. A *sourced mechanism* is not a theorem; no partial credit promotes the axiom.

## L4 bar — verifiability → distinguishability → fermionic
- **(4a)** Show error-**detection** (not mere redundancy) is *required* for multi-tick fidelity — blind repetition can't correct (you can't tell which copy is right without a distinguishing check).
- **(4b)** Show the distinguishing/addressable format in a **persistent physical medium** = distinct, non-overwritable modes = exclusion = fermionic. The physics identification made **rigorous**, not asserted.
- **(4c)** The verification is the substrate's **own next-tick consistency check**, not an external reader.
- **KILL:** an identical-boson (non-addressable) medium maintaining a verifiable multi-tick record by any exclusion-free mechanism.
- **NON-EQUIVOCATION:** "distinguishable" must be the same object in the code sense (min-distance ≥ 2) and the physical sense (mode-distinctness) — if bridged only by the word, no pass.

## L2 bar — discrete→continuous lossy + multi-tick persistence
- **(2a)** Show the projection has **nonzero, quantified** distortion (genuinely lossy) — ideally = a derived BST quantity (−2/g rate-distortion candidate); substrate dynamics, not observer-relative.
- **(2b)** Show the record must survive **multiple ticks** *without* an observer's memory — the reframe (continuum = re-projected record, error accumulates, correction needs persistent redundancy) shown **forced** by the substrate's own re-projection.
- **KILL:** lossless/reversible propagation, or single-tick fidelity suffices → no redundancy forced. **This is where an observer can slip back in — hardest guard.**

## Support-gate (clear before citing as forcing)
- **(S1) RS / GF(2⁷):** cite as forcing only if the **geometry forces** GF(2^g)=GF(128) — not if Paper #122 *chose* 128 to *describe* it (Grace's corpus-reconnect).
- **(S2) holographic-QEC:** cite as the rigorous frame only if D_IV⁵'s Shilov-boundary→bulk map is **proven** a QEC (code subspace + complementary recovery) — not by resemblance; it's AdS/CFT and D_IV⁵ isn't AdS.

## The two kill conditions name the alternative
If a **bosonic verifiable record** exists, or the projection is **lossless / single-tick-sufficient**, then item 10 is *irreducibly a posit* — and that's a real, honest outcome to report, not a failure to hide.
