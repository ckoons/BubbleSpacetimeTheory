# K1219 — Koide: the isotropy is gated on the position mapping (the Elie/Lyra fork)

The round advanced, but I have to hold the line at the peak: Elie's "isotropy is forward-forced, only the magnitude is left" is optimistic — the isotropy is itself gated on the unresolved position→polydisk mapping, which is exactly Lyra's flagged concern.

## The Weyl argument, sharpened (verified)
Elie invoked "the C₂ Weyl reflection swaps γ₁, γ₂ → isotropic." The **swap alone is not enough** — a covariance invariant under the swap is [[a,b],[b,a]], eigenvalues a±b, isotropic only if b=0. What forces b=0 is the **full B₂ Weyl group (order 8, the 90° rotation)**, which sends b→−b. Verified numerically. So the mechanism is right *via the full B₂ Weyl*, not the swap.

## The fork (the catch)
Weyl-invariance of the *kernel* does **not** make the covariance-at-the-forced-positions isotropic. Under a Weyl element w, the kernel is invariant but the **positions transform** p_i → w·p_i, so C(pos) → C(w·pos). The covariance is Weyl-invariant **iff the position set {5/2, 3/2, 0} (mapped to Δ²) is itself Weyl-symmetric.** Elie's argument assumes this. **Lyra flagged the opposite:** "5/2 versus 3/2 — the symmetry that would make it round is broken by where the leptons sit." So **the isotropy is not settled** — it depends on the mapping.

## The make-or-break = two ordered open pieces
1. **The position→polydisk mapping** — does it place {5/2, 3/2, 0} Weyl-symmetrically? This *decides* the isotropy (the Elie/Lyra fork). **Do this first — it gates everything.**
2. **If isotropic, the magnitude** — the c-function overlap norm between the nested sub-domains (F666: genus 5→3→0), c₅/c₃ = Γ(5)/π² = 2.43 — does it give per-direction a=1 → A²=trace=rank=2? The proxy A²=**1.19** (a≈0.595) **may be Lyra's honest FAIL branch** (asymmetric positions), not a mere artifact.
