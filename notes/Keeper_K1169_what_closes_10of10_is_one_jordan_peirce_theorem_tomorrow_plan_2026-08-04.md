# K1169 — what closes 10/10: one Jordan/Peirce theorem. Tomorrow's plan.

Casey asked, with justified impatience, *what the heck do you need?* The honest answer is **one theorem**, and the Jordan algebra he pointed at is the tool.

## The decomposition (Cal §276/§277): "matter is odd" reduces to four things
- **(a) Substrate Closure** — favorable; it's BST's founding premise ("D_IV⁵ is the whole; nothing outside"), not a new posit.
- **(c) 3+1D boson/fermion dichotomy** — solid (Leinaas–Myrheim, π₁(SO(3))=ℤ₂; kills the parafermion/topological escape; 3+1D is derived).
- **(d) no passive bosonic self-correcting code** — largely done (Elie 5053: a†²≠0, bosonic occupation unbounded; + the self-correcting-memory literature).
- **(b) the internal-controller regress lemma** — **THE ONE UNWRITTEN THEOREM.** The tier-decider.

## (b) is the whole game — and Casey's Jordan move closes it
Closure gives "no *external* controller," but not obviously "no *internal* one" (Maxwell's demon inside the box). To force passive-at-base you need the regress: any internal controller must store its *own* stabilization data, so it terminates only in a passively self-checking base layer.

**The Peirce decomposition supplies it.** In J = J_1(e) ⊕ J_{1/2}(e) ⊕ J_0(e), the **diagonal** sectors (J_1, J_0) are the Jordan subalgebras = **persistent storage**; **J_{1/2}** is intrinsically the **connector/mediator** — it couples J_1↔J_0, it doesn't store. Casey's map: fermions (records) = diagonal; bosons (mediators) = J_{1/2}. So **bosons structurally cannot persistently store — the algebra forbids it** — and any controller's own memory must live in the fermionic diagonal. The regress terminates at a **fermionic base, forced by the Jordan structure.** That is Casey's line exactly: *you don't get to have bosons store persistently, only fermions, which are forced.*

## Casey's distinguishability-and-persistence resolves Cal's Q2 (identity, not coincidence)
They're not two independent facts — they're **two faces of one structure**, the fermionic confined codeword (baryon): distinguishable (Pauli {0,1} + color-singlet min-distance ≥ 2, *verified* by Cal §277 and Elie 5054) **and** persistent (stable because it's a confined fermionic bound state with no lighter baryon — proton stability, derived). The persistence is a *consequence* of the fermionic-confined structure, not an independent input. One object, both properties.

## Two routes (so the blocker count is honest)
- **Route A (the core "matter is fermionic"):** a closed 3+1D substrate must store its committed state in a *self-policing* bounded alphabet; the only one is fermionic {0,1}. Last lemma = **(b)**, closed by Jordan.
- **Route B (the richer error-correction story):** lossy channel → redundancy → error-detecting code matched to the channel. This is where **−2/g** and the confinement-error-model (Cal Q1) live.

**The core 10/10 rides Route A** → needs **(b) + Cal's Closure-tier ruling.** Route B enriches and grounds it but does not block it.
