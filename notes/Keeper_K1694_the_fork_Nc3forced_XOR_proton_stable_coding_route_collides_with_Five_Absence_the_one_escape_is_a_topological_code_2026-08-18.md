# K1694 — the fork: {N_c=3 forced} XOR {proton stable}; the coding route collides with Five-Absence; the one escape is a topological code

## The team converged (credit Casey, ratify all four legs)
Casey's reframe (**the record is the baryon**) is credited and it held: it dissolved the lepton objection and re-sorted glue (`ε_abc`) from record (the 3 quarks). And the team agreed, unanimously and cleanly:
- **The winding route is circular** — `N_c=3` as trefoil-winding or short-root-multiplicity is `n_C−2 = a` (the same `a` behind `N_c`, Wallach, `C₂=2a`). It *describes* D_IV⁵; it can't force it. Zero forcing content.

## The crux is a fork — and it collides with a flagship
Elie's decisive point: the two routes **predict different physics.** Topological → `B` exactly conserved → `τ_p` **infinite**. Coding → `B` by active correction → `τ_p` **finite** (`[3,1,3]` fails on two hits per window). So **"the record error-corrects, therefore N_c=3" is *also* "the proton decays."** You cannot assert the forcing and imply exact stability without taking both mechanisms at once.

**And the coding-forcing route's finite `τ_p` violates the Five-Absence flagship — "no proton decay," a structural commitment where any positive detection refutes BST.** So BST is committed to the *topological* (exactly-stable) route — which is the *circular* one. **On the current corpus, `N_c=3` is not forced by error-correction, because BST is committed to exact stability.** Two more obstructions pile on: Cal's P2b double-use (minimality can't both close #67's two-stage commit *and* add a third correcting stage), and Lyra's physical read (the visible mechanism is *rejection* — the singlet vanishes — not *repair*).

## The one escape — and it's the real frontier
A **topological error-correcting code** (Kitaev/toric), where the topology *is* the repair. That would dodge all three obstructions at once: exact stability (topological, no rate-process, no decay → Five-Absence preserved), no third rate-stage (no P2b conflict), repair-by-topology (not rejection). If the baryon is such a code — the winding *is* the `[3,1,3]` repair — then `N_c=3` is forced, the proton is exactly stable, Five-Absence holds, and `n_C=5` is fully intrinsic: **the whole prize, no fork.** But it isn't banked, and it requires exhibiting the winding→code map — exactly the type-crossing that failed in K1686.
