## B. The linear-algebra statement (a theorem, 1950–2003, in the corpus's vocabulary)

- **The successor residue:** ρ(x) = {x} (fractional part) — the tick's arithmetic shadow. (Mellin on the line: −ζ(s)/s.)
- **The multiplication flow, restricted to the integers:** D_k f(x) = f(x/k), k = 1, 2, 3, … A commuting semigroup, D_k D_m = D_km, generated by the primes; each D_k is a strict contraction. Under Mellin, D_k = multiplication by k^{−s}: the coordinate shifts of Bohr's polydisc (z_p = p^{−s}).

> **Nyman–Beurling (1950/55), Báez-Duarte (2003).** RH ⟺ χ lies in the closed span of {D_k ρ : k ≥ 1} in H.
> Equivalently: **ζ is a cyclic vector for the integer-dilation semigroup** on the weighted Hardy space of the half-plane Re s > ½.

**The obstruction, exhibited (the direction that is one line of linear algebra).** Let ρ₀ be a zero of ζ with Re ρ₀ > ½. Point evaluation at ρ₀ is a bounded functional on the Hardy space — its reproducing kernel k_{ρ₀} is a vector. Every P(s)·ζ(s) (P a Dirichlet polynomial) vanishes at ρ₀, so **k_{ρ₀} ⊥ [ζ]**, while ⟨1, k_{ρ₀}⟩ = 1 ≠ 0. Therefore χ ∉ [ζ].

# H = L^2((0,inf), dx/x^2); r_k(x) = {x/k}; chi = 1_{x>=1}; d_N^2 = 1 - b^T G^{-1} b
import numpy as np, math
from scipy import integrate
g = 0.5772156649015329
frac = lambda x: x - np.floor(x)
def inner(k, m, X=4000.0):
    bps = np.unique(np.concatenate([np.arange(0, X+k, k), np.arange(0, X+m, m)]))
    bps = bps[(bps > 0) & (bps <= X)]; tot = 0.0; lo = 1e-9
    for hi in list(bps) + [X]:
        if hi <= lo: continue
        tot += integrate.quad(lambda x: frac(x/k)*frac(x/m)/x**2, lo, hi, limit=200)[0]; lo = hi
    return tot + 0.25/X
def b_k(k, X=4000.0):
    bps = np.arange(k, X+k, k); tot = 0.0; lo = 1.0
    for hi in list(bps[bps > 1]) + [X]:
        tot += integrate.quad(lambda x: frac(x/k)/x**2, lo, hi, limit=200)[0]; lo = hi
    return tot + 0.5/X
N = 8
G = np.array([[inner(k, m) for m in range(1, N+1)] for k in range(1, N+1)])
b = np.array([b_k(k) for k in range(1, N+1)])
for n in range(1, N+1):
    print(n, 1 - b[:n] @ np.linalg.solve(G[:n, :n], b[:n]))
