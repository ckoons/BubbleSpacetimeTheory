# BST Guideline — Research Tiers and Publication Tiers

**Casey's charter (2026-08-03):** *"As researchers we push for forced-by-geometry and use terms where we understand the difficulty of proof. For publication we need terms the general physics audience can accept, that are fair and accurate. I don't want to worry about underselling a theory that derives so much from D_IV⁵ and is its own worst public critic. We stand behind what we publish and ask others to respond — and we set the public benchmarks fairly, using GR as our benchmark norm."*

## The principle
BST keeps **two** tier ladders because one ladder cannot do two jobs:
- **The Research tier keeps us HONEST** — fine-grained, self-critical, the instrument that finds the truth (it caught the dark-energy proxies). Here we push hard for *forced-by-geometry* and never soften.
- **The Publication tier keeps us FAIR** — coarser, benchmarked to the standard the field actually uses (GR), presenting results the way physics presents its own.
- **The fixed mapping keeps us from confusing them.** The publication tier is a faithful, defensible *coarsening* of the research tier — never an inflation. This is standard practice (engineering: design margins vs spec sheets; trials: exploratory vs pre-registered endpoints). It is *more* honest than a single ladder, because publishing the internal audit's vocabulary misleads by **underselling**.

## Research Tiers (internal — unchanged, keep sharp)
| Tier | Meaning |
|---|---|
| **Proved** | Complete proof. |
| **Derived** | Forced by the geometry — complete forcing chain, zero free input — not yet a closed proof. |
| **Partially Derived** | Structure/integers forced; one combination or scale open as a *reachable derivation target* (explicit split). |
| **Identified** | Right object identified, structure forced; value rides on one *external* input (not derivable — a physical scale). |
| **Conditional** | Depends on a stated conjecture. |
| **Structural** | Qualitative / order-of-magnitude geometric consequence. |
| **Proxy-Register status** | FORCED-geometry vs LABELED-proxy (imported/scaffold) — gates the publication tier. |

## Publication Tiers (external — GR-benchmarked, fair, accurate)
| Publication tier | Plain-physics meaning | Where GR's comparable terms sit |
|---|---|---|
| **Derived** | Forced from the geometry. | GR's *marble* — Gμν. Same level. |
| **Structure-Derived** | The geometry forces the *form*; one piece is set by an input or is a remaining forced target — stated explicitly. | **Nothing** — GR's G, Λ, w have no derived structure. This tier is **above** GR's source terms. |
| **Input** | A named physical input, stated plainly. | GR states G and Λ exactly this way — no apology. |
| **Indicative / Lead** | A qualitative geometric result or an open lead. | — |

## The fixed mapping (deterministic — no case-by-case bumps)
| Research tier | → Publication tier | Split-note to state |
|---|---|---|
| Proved, Derived | **Derived** | — |
| Partially Derived | **Structure-Derived** | "form forced; [one piece] a remaining forced target" |
| Identified | **Structure-Derived** | "form forced; value set by [the named input, e.g. the cosmic age]" |
| (the named input itself) | **Input** | state plainly, GR-style |
| Conditional | **Indicative / Lead** | "conditional on [X]" |
| Structural | **Indicative** | — |
| Proxy-Register: LABELED-proxy / scaffold | **not BST-Derived** — "reproduced standard result" or held **Indicative** until recomputed | e.g. G stays here until the a₁-operator-on-genuine-Q⁵ closes (Register #3) |

## GR is the benchmark norm — how to write it
- **State inputs plainly, like GR states G.** "The cosmological-constant value is set by the age of the universe" is the same *kind* of sentence as "the expansion rate is set by the matter density" — a clean input, **never a confession.** No "only," no apology. ([[feedback_dont_diminish_identified_state_inputs_like_GR]])
- **Lead Structure-Derived with the derived structure**, then name the one piece. Honest (names the piece) *and* fair (leads with what's forced).
- **Use the GR-benchmark column when it helps.** BST's Structure-Derived tier sits *above* where GR's most celebrated source terms land — say so, factually, using the field's own ruler.
- **Falsifiable-because-derived is the sharpest claim.** GR/ΛCDM *assume* the equation of state (unfalsifiable); BST *derives* its structure (falsifiable). A theory that can be killed by w is doing more science than one that fits it.

## The four guardrails (what keeps this honest, not spin)
1. **Fixed mapping, never case-by-case.** Research-Identified → Publication-Structure-Derived, *always*. The moment we bump *this* result because it feels strong, it's laundering. Uniform rule or nothing.
2. **The research tier is the gate.** Publication never exceeds what the research tier supports. It is a fair *re-expression*, never an inflation; the research tier keeps its veto.
3. **Full traceability.** Every publication-tier claim carries a pointer to its research-tier record + its Proxy-Register status. A hostile referee gets the fine detail instantly.
4. **Benchmark-anchored, not vibe-based.** "Fair" is operationalized by the GR column — written down, applied to every rung.

## Hostile-referee hardening (Cal §230 — how the mapping survives an adversarial read)
Three ways a hostile referee attacks the mapping, and the standing fixes:
1. **"Structure-Derived misread as Derived."** A hostile reader drops the "Structure-" qualifier and hears the word they want. **Fix: never a bare badge** — always write *"structure derived; [quantity] set by [named input]"*, with the input co-stated in the same breath, as prominently. If the label can stand alone, it reads as Derived.
2. **"'Above GR' is rhetoric."** Comparing our best case to GR's inputs to look good invites a pounce. **Fix: lead with parity-of-standard, which is unassailable** — *"GR derives the field equations and takes G and the matter content as inputs, unapologetically; hold BST to that same standard, not a harsher one."* Cite a specific "above" only where it's like-to-like fact (the cc structure is derived where GR's stress-energy is pure input). Never a blanket "BST > GR" — that's the sentence a referee pounces on.
3. **The hidden-input hunt (deepest).** "One input, the cosmic age" is honest only if it is genuinely the only free thing. **Fix: per entry, hunt for a second scale, a stray O(1) fudge, or a convention choice that's really a fit** — before it publishes. (Cal audits the mapping table entry-by-entry against these three.)

## Interlock with the accurate-corpus program
This guideline and the **Proxy Register** are one system: the Register decides *forced-geometry vs proxy* (research tier), which feeds the publication tier via the fixed mapping. A LABELED-proxy (e.g. G while it rests on the F60 scaffold) **cannot** be published as Derived — the Register status gates it. So the two-tier system does not *enable* over-claiming; it *prevents* it, while fixing the underselling.
