## The rule (why elimination is dangerous)
> **Eliminating X is a scope-shed: X was load-bearing for SOMETHING. Before banking "drop X / retire X / X not needed," grep what X carries — and confirm every load it carried is either re-homed or genuinely gone.** A held/eliminated object can't be silently removed from a chain that still uses it (companion to "a held premise can't be a link in a banked chain").
