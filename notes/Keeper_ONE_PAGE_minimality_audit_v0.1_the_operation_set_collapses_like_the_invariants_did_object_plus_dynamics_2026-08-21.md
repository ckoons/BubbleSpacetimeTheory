# The one-page minimal generating set — minimality audit (which generators are real?)

- **NECESSITY = independence** — each generator cannot be derived from the others (else it isn't a generator; it's a reading). *This is the Keeper half — the minimality audit.*
- **SUFFICIENCY = spanning** — every observable is *one operation at one address* (K-type). *This is Lyra's dual-register half.*
