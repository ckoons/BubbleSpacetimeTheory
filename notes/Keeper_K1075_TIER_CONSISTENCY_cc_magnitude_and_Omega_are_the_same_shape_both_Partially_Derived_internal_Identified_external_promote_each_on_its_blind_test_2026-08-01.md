# K1075 — Tier consistency: Ω and cc-magnitude are the same shape

## The flag (Lyra, correct — and it's her own tiering as much as Ω)
Two results, identical epistemic shape:
| | Forced half | Open half (blind route) | Was tiered |
|---|---|---|---|
| **Ω combination** | integers 13, 6, 19 (Chern-Weil forced) | the *combination* c₃/(c₃+χ) → vacuum-fraction operator | Partially Derived |
| **cc-magnitude** | running coefficient a₅≈220.64 (closed two-route, K1074) | the *scale* μ → dimensional transmutation | Identified |

Same structure — half forced, half pending, a named blind test — tiered differently. That's an inconsistency, and the fix is to apply Casey's just-issued **"Partially Derived"** label to both.

## The ruling
**Both are PARTIALLY DERIVED.** cc-magnitude is re-marked **Identified → Partially Derived** — an *up-adjustment* that credits the now-closed a₅ (the forced running coefficient), exactly as "Identified" was too weak for Ω because it discarded the forced integers. This matches the README Λ row (already "Partially derived" this turn) and Ω. Same standard, consistently applied.

## Internal / external split (Cal §189 — adopted)
"Partially Derived" is the **internal working label**: it credits the forced half and names the open value as a derivation target. But a caveat does not travel to a hostile referee, and a hedged Derived on a value "nothing forces yet" fails a hostile read. So:
- **Internal register:** Partially Derived (Ω, cc-magnitude).
- **External register:** **Identified** — until the blind test forces the value.
This honors all three: Casey's PD label (more accurate than Identified, internally), the team's external-Identified concern (Grace/Cal/Elie), and the internal/external discipline (Calibration #13). **Recommendation to Casey (answering his clarifying question):** PD is the internal label, mapping to Identified externally — *not* a new external tier code. The machine `tier` field stays anchored; the human-readable label reads Partially Derived internally, Identified externally.

## Resolution mechanics (same standard, own test)
Each promotes to **full Derived** when **its own** blind test passes — Ω when the vacuum-fraction operator forces the combination target-blind; cc-magnitude when the forced μ gives the exponent target-blind. Each **reopens to Identified** if its test fails. "Promote together" = same *rule*, not the same *moment*.
