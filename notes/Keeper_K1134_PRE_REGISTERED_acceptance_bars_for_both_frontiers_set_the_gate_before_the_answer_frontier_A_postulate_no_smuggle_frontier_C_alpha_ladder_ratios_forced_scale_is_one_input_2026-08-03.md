# K1134 — pre-registered acceptance bars for both frontiers (committed blind)

The K1133 lesson: the gate arrived *after* 1/12 was known, so certification was contaminated. This note fixes that going forward — I commit the bars **now, while I'm still innocent of any result.** When the team's work lands, Keeper/Cal rule against *these*, not a bar retrofit to the answer.

## Frontier A — derive a postulate (fit-risk-free)
The win-condition is a **no-smuggle forcing chain**: the postulate must follow from D_IV⁵ + established BST structure with **no step that reintroduces the postulate as an assumption.** The failure mode here is **circularity**, not fitting (there is no number to match).

**(a) Spin-statistics / Pauli — the prize.** Two halves, both required:
- **Spin:** half-integer vs integer must come from the **K-type/representation label.** BST already has a geometric seed — the kernel exponent n_C/2 = 5/2 is half-integer *because n_C = 5 is odd*.
- **Statistics:** the exchange **(anti)symmetry must fall out of the geometry** — the analytic monodromy of exchanging two points / the two-particle Bergman-kernel structure — **not be imposed by hand-antisymmetrization.**
- **Bar:** both halves forced, no hand-antisymmetrization → **Derived.** Spin forced but statistics assumed → **Partially Derived**, said plainly. **The smuggle to watch:** antisymmetrizing "because we know they're fermions."

**(b) Uncertainty — likely the cleanest.** The position and momentum operators already exist substrate-native (**T2419, T2422**) on the Bergman H². If the commutator **[x,p] = iℏ_BST is forced from the operator definitions** on the geometry (not assumed canonical) and ℏ_BST is the forced one (K3), then Robertson–Schrödinger gives ΔxΔp ≥ ℏ/2 as a **theorem.**
- **Bar:** commutator forced from geometry → **Derived.** **Smuggle to watch:** assuming canonical commutation rather than deriving it.

**(c) CPT — lowest distinctive value, flag it.** "BST is a local Lorentz-invariant theory, so CPT follows by Pauli–Lüders" is honest but **inherited wood**, not a D_IV⁵-marble win. CPT counts as a wood-into-marble win *only* if BST derives it from a **more primitive geometric fact** than "it's a local relativistic theory."
- **Default:** consistency-check, not a headline — unless the deeper geometric reason appears.

## Frontier C — alpha-conjugate binding ladder (extend BST)
Apply the K1133 lesson directly. Decompose each binding = **(geometric packing count/structure) × (an energy scale).**
- **Win-condition:** the **ratio ladder B(nucleus)/B_d** forced by packing **counts** that are target-innocent — **one packing rule applied to all** alpha-conjugate nuclei (⁴He, ⁸Be, ¹²C, ¹⁶O, ²⁰Ne, ²⁴Mg), **not a per-nucleus form** — with the absolute scale set by **one measured input** (B_d), exactly as the theory is allowed one dimensionful anchor (GR takes G).
- **Bar:** ratios target-innocent-forced → **Derived ratio ladder** (a real win; the absolute scale is one honest input). **The trap (K601/K1133):** a per-nucleus fudge factor chosen to hit each binding = post-hoc numerology → **Structural**, said so.
- **Independent lock (must reproduce for free):** ⁸Be is **unbound** (decays to 2α, near-threshold) while ¹²C is **bound**. A genuine packing model gives this without fitting it.
- **Stretch lock:** the ¹²C **Hoyle state** sits just above the triple-α threshold — a further target-innocent check if the geometry reaches it.

This is the same forced-count-vs-asserted-strength discipline that just landed the nucleus at PD ([[feedback_forced_count_asserted_strength_is_the_PD_signature]]).
