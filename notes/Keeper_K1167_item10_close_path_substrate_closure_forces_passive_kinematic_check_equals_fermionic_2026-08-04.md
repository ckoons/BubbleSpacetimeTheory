# K1167 — what closes 10/10: Substrate Closure forces a passive check = fermionic

Casey asked the question directly. The close-path is now specific and corpus-grounded.

## Cal's obstacle (§275, correct)
"Distinguishable ⟹ fermionic" is false at face value: **bosonic QEC codes exist** and are addressable (GKP, cat, binomial). Addressability alone doesn't force fermions.

## The defeater (what closes it)
Those bosonic codes **all require active stabilization** — syndrome measurement + feedback ([literature-confirmed](https://arxiv.org/pdf/2412.02442): passive self-correction is "the oldest unsolved dream" of QEC; GKP/cat/binomial are actively stabilized). Active stabilization = an **external controller = a watcher**.

**The substrate is closed** (Substrate Closure Principle, corpus, Casey-named — no external referent). So there is **no controller**. The error-check must be **passive** (kinematic, built into the state space):
- **Fermionic exclusion** is a kinematic bounded alphabet — {0,1} per mode, enforced by antisymmetry, **free, no controller**.
- A **bounded bosonic code** requires **active projection** into a code subspace — the controller Closure forbids.
- In **derived-3+1D** (Grace: boson-unbounded XOR fermion-{0,1}; parafermions/anyons need 2+1D), the only kinematic self-verifying occupation code is **fermionic**.

⟹ **the closed substrate's self-verifying records are fermionic** — non-anthropic. *Cal's counterexample becomes the exact place the corpus principle bites: bosonic codes exist, but they need the very controller Substrate Closure forbids.*

## This reduces item 10 to ONE theorem (Elie/Lyra)
> **In 3+1D, the only kinematic (passive, no external stabilizer) error-detecting occupation code is fermionic exclusion.**

Rides three things we already have: **Substrate Closure** (corpus) + **derived-3+1D** (Casey #14 / axiom 6–9) + **verifiability** (Pauli {0,1} = built-in parity check, Elie 5052). It's the right framing of Cal's "ballgame" toy: naive "min-distance ≥ 2 ⟹ fermionic" is false (his counterexample), but **"min-distance ≥ 2 + passive (Closure) + 3+1D ⟹ fermionic"** defeats it.
