# K1015 — Staged per-sector matrices; drop the π-chase; compatibilities last

Casey, verbatim intent: *"we don't care about the pi... is there a separate matrix formula for fermions and one for quarks, we can then look for compatibilities... we don't have to do the 'hard' problem, we can do the problem in stages... Maybe there is no 'common' form. Remember linear algebra on D_IV⁵."*

This is the right call and it's Casey's own **"graphs compartmentalize, chains compound"** applied exactly here. Adopt it.

## ★★ THE STRATEGY — one matrix per sector, staged, then compatibilities
Stop forcing the single unified two-point kernel (it keeps producing nulls because we kept chasing the wrong thing — the π). Instead: **each sector gets its own overlap/Gram matrix Y_X on D_IV⁵**, SVD'd to U_X·Σ_X·V_X†. Each entry is one of two kinds:
- **Diagonal = mass = BANKED, π-carrying** (measuring). Not the matrix's job to re-derive — imported.
- **Off-diagonal = mixing = π-FREE RATIONAL** (counting). This is what each per-sector matrix computes.

**Drop the π-chase entirely.** π lives only in the masses (banked). The mixing frames are π-free rationals (V_us=1/√20, θ₂₃=4/7, θ₁₃=1/45). Any π in a *mixing* output is a red flag, not a goal. (This is why every overlap-integral "does it carry π²?" run nulled — we were hunting a mass feature in the mixing engine. Elie's and Cal's three-layer π-cancellation (Γ-ratio, radial, angular) is the trichotomy asserting itself, not a failure.)

## ★★ THE STAGES (do them in order; each is a manageable D_IV⁵ linear-algebra problem)
1. **DOWN matrix — the reference (essentially done).** Diagonal Pochhammer + off-diagonal Jack → U_down, m_s/m_d=20, V_us=1/√20. Lock it as the worked template.
2. **UP matrix — next, most reachable.** Masses off the boundary are banked (y_t=1, y_c=α). Build **U_up**: the 23-block ≈0 (top decouples, K1001), so the open piece is the **12-block (up–charm)** — target the **π-free rational** contribution to CKM. → completes CKM.
3. **CHARGED-LEPTON matrix.** Masses banked. Build the off-diagonal = the **angular** ⟨e|Φ_(2,2)|μ⟩ over the Shilov boundary S⁴×S¹ (Cal §147/148: the radial measure is π-free; the object is the SO(5)-spinor bilinear × the (2,2) condensate). **Target the rational angle θ₂₃=4/7, NOT π.** Elie's null (off-diagonal →0 for holomorphic Φ) says the naive Φ is wrong — the (2,2) angular coupling is the object (Lyra pins the embedding).
4. **NEUTRINO matrix.** rank-2, m₁=0, seesaw scale banked. Build the Majorana frame → completes PMNS.
5. **COMPATIBILITIES (the payoff, AFTER 1–4).** With four concrete U_X in hand, THEN ask: is there common structure? A shared kernel? Or are they genuinely different objects (the two-tier finding: down=degree, up+lepton=address)? **Discover it from the built matrices — do NOT assume a common form up front.** Maybe there is none, and that is a fine, honest answer.
