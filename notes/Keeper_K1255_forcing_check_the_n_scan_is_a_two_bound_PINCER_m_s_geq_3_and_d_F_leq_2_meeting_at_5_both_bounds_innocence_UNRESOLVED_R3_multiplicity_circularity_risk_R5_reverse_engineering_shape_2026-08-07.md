# K1255 — the forcing n-scan is a two-bound pincer (n≥5 ∧ n≤5); both bounds' innocence is unresolved

Working Lane 3 (K1251's checks) first-thing with fresh context, applying the day's lesson to myself.

## The n-scan logic — verified
Within type IV: (n odd) ∧ (m_s = n−2 ≥ 3, R3) ∧ (d_F ≤ 2, R5) ⟹ **n = 5 unique** (n=3 fails m_s≥3; n=7,9,… fail d_F≤2). And d_F(n) = (n−1)/2 reproduces Paper B's values. The logic is clean *given* the two bounds and the d_F formula.

## The structure it actually is — a PINCER (the honest reframe)
The two criteria are two **opposite** bounds on n meeting at 5:
- **R3 ⟺ m_s ≥ 3 ⟺ n ≥ 5** — a *lower* bound (from convergence).
- **R5 ⟺ d_F ≤ 2 ⟺ n ≤ 5** — an *upper* bound (from the Selberg class).

n=5 = (n≥5) ∧ (n≤5). Elegant **if** both bounds are independently prior — but this is **exactly the shape a reverse-engineered pair would take** (one lower + one upper, tuned to pinch at the target). So the forcing's honesty is *entirely* the independent-priorness of these two bounds.

## Check (b) — R3 (I resisted over-claiming)
The coincidence is real: ⌊n_C/2⌋ = 2 = rank **only** at n ∈ {4,5}, so at n=5 "convergence order set by ⌊n_C/2⌋" vs "by rank" are indistinguishable. I was tempted to call it rank-determined (hence innocent, since rank=2 is constant across type IV). **The one-line check caught me:** the inverse spherical transform converges when the test function beats the Plancherel density |c(λ)|^{−2}, whose growth degree = 2·(positive roots *with multiplicity*) = dim − rank — which **involves m_s** (= n−2), not just the rank. So the required order plausibly **depends on the multiplicities** → "m_s ≥ 3" could be a multiplicity-quantity constraining itself (partly circular). **R3's innocence is unresolved.** The precise check: is the convergence threshold set by dim(a*) = rank (prior → innocent) or by the Plancherel growth = the multiplicities (n-dependent → circular)? Needs the actual Harish-Chandra estimate.

## Check (c) — R5 (the reverse-engineering shape)
d_F ≤ 2 ⟺ n ≤ 5 **exactly** (since d_F = (n−1)/2). So "the substrate's zeta lies in Selberg degree ≤ 2" is, numerically, just "n ≤ 5." The Selberg class admits *all* degrees with the same usable properties, so restricting to ≤ 2 needs a **prior reason** independent of "gives n=5" — not yet exhibited.

## The honest net (sharper, both directions)
The n-scan logic is verified, but the forcing is a **two-bound pincer** whose honesty = both bounds' independent priorness, and **both carry an open risk** (R3 multiplicity-circularity; R5 the ≤2⟺n≤5 shape). This does **not** refute the forcing — it localizes the *entire* honesty question to "are these two opposite bounds independently prior, or a lower+upper tuned to pinch at 5?" The promotion path is two specific harmonic-analysis checks (R3's threshold rank-only?; R5's degree-≤2 a prior necessity?). Until then, Paper B stays **conditional**, and the pincer + both risks go into the paper so a referee sees exactly the risk.

**Discipline:** I nearly asserted "R3 rank-determined ⟹ innocent"; the one-line check (Plancherel growth involves the multiplicities) caught it. The auditor's obvious step needs the same check as anyone's.
