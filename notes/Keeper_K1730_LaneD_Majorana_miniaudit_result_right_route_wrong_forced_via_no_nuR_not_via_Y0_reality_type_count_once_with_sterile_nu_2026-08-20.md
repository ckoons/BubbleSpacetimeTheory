# K1730 — Lane D Majorana mini-audit: result right, route wrong, count once

> **✓ CO-SIGNED by Cal (§635) + Keeper (K1735). Cal independently found the Y=0 route is not a census read; this note found WHY — the only real Y=0 fermion is ν_R, which BST forbids, so the Y=0 route names a particle the theory says doesn't exist. K1730 (mechanism: Majorana via no-ν_R) and §634 (experiment pairing: LEGEND-1000/nEXO→NULL, detection refutes) are complementary and both needed. Sourced 0νββ numbers: K1734.**

## The smell (verified from first principles)
A bare Majorana mass `ψᵀCψ` is gauge-invariant **iff the field's rep is real/self-conjugate** (net quantum numbers zero). The **only** SM fermion with a real rep (singlet, Y=0) is **ν_R** — and **BST forbids ν_R** (T1949, Möbius, "no sterile neutrino"). So Lyra's *"the lone Y=0 fermion stays real → Majorana"* is describing **ν_R's** reality type — a particle the theory says does not exist. You cannot invoke a forbidden particle's reality type as the mechanism.

And the *actual* neutrino field ν_L sits in the doublet `L=(ν,e)`, rep `(2, Y=−1/2)`: Y≠0 → **complex** → a bare Majorana mass for ν_L is gauge-**forbidden**. The census hands you the opposite of what the stated route claims. This is the **9th relocating-not-resizing** candidate this month — right answer, wrong slot (cf. chirality-from-the-quaternionic-block last round).

## The correct route (cite this)
1. BST forbids **ν_R** (T1949, forced from Möbius).
2. No ν_R ⟹ **no Dirac mass** (a Dirac mass couples ν_L↔ν_R).
3. Neutrinos **are** massive (oscillations — empirical, or the BST ν-package seesaw; **grep it**, don't re-derive).
4. The only mass a massive ν_L can then have is **Majorana**, via the **unique dimension-5 operator** `(LH)(LH)/Λ` (two Higgs soak up hypercharge+SU(2); ΔL=2).

⟹ **"no ν_R + neutrino massive ⟹ Majorana."** That is the sentence the prediction carries — not "Y=0 → real."

## Tier
Majorana **nature** = Derived-conditional-on-massiveness (structure forced by no-ν_R + dim-5 uniqueness); **mass scale** = Identified/package-dependent. Forced-structure + elsewhere-value = the **Partially-Derived** signature. State it that way; don't inflate to fully-Derived.

## Count-once (load-bearing)
