# K1236 — the interlock off-by-one is confirmed: n_C=5 is NOT forced by N_c=3; and T2113 is Identified-pending, not proved (two self-catches)

## Cal's off-by-one (§323) — ruled correct
My chain: N_c=3 → 3 space (T2545) → 3+1=4D → SO(4,2) → SO(5,2) bulk (T2113) → Type IV₅ → n_C=5. The group bookkeeping breaks it:
- **D_IV^n = SO(n,2)/[SO(n)×SO(2)], complex dimension n.** So **SO(4,2) = D_IV⁴ (n_C=4)** and **SO(5,2) = D_IV⁵ (n_C=5)**.
- The chain's boundary is 4D, whose conformal group is **SO(4,2) = n_C=4.**
- **Standard holography (AdS/CFT and Rehren) shares the group:** a 4D CFT with conformal group SO(4,2) has bulk AdS₅ = SO(4,2)/SO(4,1), **isometry SO(4,2) — the same group**, = D_IV⁴-worth (n_C=4), **not** SO(5,2)=D_IV⁵.

So the step "SO(4,2) → SO(5,2)" is exactly where the +1 that separates n_C=5 from n_C=4 lives, and standard holography **does not provide it.** The naive chain lands on **n_C=4**, and the +1 was **smuggled.**
