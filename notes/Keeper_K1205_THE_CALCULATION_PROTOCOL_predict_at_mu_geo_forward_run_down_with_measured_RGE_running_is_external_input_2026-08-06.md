# K1205 — the calculation protocol: predict at μ_geo forward, run down with measured RGE

Casey's insight is the key: **the running is external measured physics, not a derivable interior object of D_IV⁵.** So we stop pinning "which scale makes the weights clean" and instead predict the geometric Yukawas at the geometry's own scale, run them down with the *measured* RGE, and compare. μ_geo is geometric (BST-derived); the running is measured input (like G, c in GR). No scale knob.

## Why this dissolves Caveats 1–2 correctly (not by dodging)
Grace's nine-Yukawa run found no single scale makes all weights clean integers. Under this frame that's **expected and fine**: the clean integers only need to hold at μ_geo; the weights at 2 GeV / M_Z / v are the *run-down* values, shifted off the integers by the measured running. "No single clean scale" was only a problem under the wrong assumption that the observed low-scale weight *is* the geometric integer. It isn't — it's the integer plus running.

## The derived-vs-external split (GR-honest — state the inputs plainly)
- **Derived by BST** (interior objects): μ_geo; the nine geometric weights w_f (discrete-series lowest weights); y_geo,f = n_C^{−w_f}; the k=0 ground-shell gap.
- **External measured input** (the "running"): the SM 2-loop QCD + 1-loop EW RGE, flavor thresholds, α_s(M_Z)=0.1180. **This is not a weakness** — GR takes G, c as measured; BST takes the SM running as measured and derives the geometric boundary condition. Say so.

## The four-step protocol (forward, no back-solving)
1. **Lyra — derive μ_geo** from the geometry, *blind* to what fits. The overlap is with the condensate O = F603 = the Higgs, which lives at **v** → μ_geo = v is the natural candidate; a UV/cutoff scale (Koons-tick-related) is the alternative. State it with its BST justification before looking.
2. **Lyra — predict all nine geometric weights w_f at μ_geo, forward**, from the discrete-series representation theory (up = spinor at g=7, generalized to the whole spectrum). Blind to the data. Include the +1 spinor shift (scalar at C_2 → fermion at g) *derived*, not asserted.
3. **Elie + Grace — run y_geo,f(μ_geo) down** to the measurement scale with the **measured SM RGE** (Machacek-Vaughn 2-loop, or PyR@TE/REAP; PDG inputs). No free parameters.
4. **Grace + Keeper — compare and score in σ** (measured-mass errors + running uncertainty). Forced: both BST inputs are forward, the running is measured.

## What the team needs from the web (Casey flagged this)
- **Xing, Zhang & Zhou, "Updated Values of Running Quark and Lepton Masses"** (Phys. Rev. D 77, 113016 + updates) — all nine charged-fermion MS-bar masses at 2 GeV, M_Z, and higher, running done properly, with uncertainties. *(Grace assembles the reference table.)*
- **The SM 2-loop Yukawa RGE** — Machacek & Vaughn (1984–85), or a code (PyR@TE, REAP, SARAH). *(Elie implements the run-down.)*
- **PDG 2024** — α_s(M_Z), α, thresholds, pole/MS-bar masses with error bars.

## The honest fork (state it up front — this can falsify the up-quark result)
If μ_geo = v and w_up = 7, then y_geo = 5⁻⁷ at v predicts m_up(v) ≈ 2.2 MeV — but measured m_up **at v** is ≈ 1.0–1.1 MeV (it runs down), a factor ~2 miss. The clean 5⁻⁷ matches m_up at ~2 GeV, **not** at v. So under this protocol the naive "w_up = 7 at v" may **fail**, exposing 5⁻⁷ as a ~2 GeV-scale coincidence — *or* μ_geo isn't v, *or* the geometric weights are different integers that run down to the observed values. The protocol must be allowed to find any of these.

## Why this is the right way regardless of outcome
Pass → a real derivation of the fermion spectrum, with the running as a stated external input (GR-honest). Fail → the naive tower is falsified cleanly and we learn 5⁻⁷ was scale-specific. Either way: forced, forward, no scale knob.

## Tier
Unchanged pending the protocol: up-quark 5⁻⁷ Identified (anchor, ~2 GeV, scale-caveated); tower soft; **not Derived**; charm degenerate. Nothing banks until μ_geo is derived, weights predicted forward, run-down computed with measured RGE, and the σ-comparison passes.
