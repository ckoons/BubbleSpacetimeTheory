## ★ The authoritative fact (primary-source, target-innocent)
For an irreducible bounded symmetric domain Ω, the Bergman kernel is
> **K(z,w) = h(z,w)^{−γ}**, h = the unique **generic norm** (degree = rank r), γ = the **genus** = **2 + a(r−1) + b**, with a, b the FK root multiplicities.

For **type IV_n** (the Lie ball, complex dimension n): tube type, r = 2, a = n−2, b = 0 ⟹ **γ = 2 + (n−2)·1 + 0 = n**. So:
> **D_IV⁵: genus γ = 5 = n_C** (a = 3 = N_c, b = 0, r = 2). Matches Cal's independently-ratified FK-roots value (genus p = (r−1)a + 2 = 5).

**⟹ the scalar Bergman exponent of D_IV⁵ is the genus = 5 = n_C.** (Sources: the FK genus/generic-norm formula K = h^{−γ}; standard for bounded symmetric domains including Lie balls — see the generic-norm definition N = (V·K)^{−1/γ} in the literature below.)

## ★ What this settles
- **g = 7 does NOT appear in the scalar Bergman exponent.** The exponent is genus-governed (= 5 = n_C); g = 7 is the *signature total p + q*, a different invariant. **This is primary-source confirmation of K1424** — Paper118's "K_B = det(1−zw̄^T)^{−g/rank} = D^{−7/2}" uses g=7 *as if it were the genus*, which is precisely the mislabel my State-of-Spine audit corrected. **Paper118 lines 41–43 are wrong on the exponent; the relabel stands (Grace's 7/2 sweep).**
- **The 5-vs-5/2 is a convention, not a conflict.** γ = 5 is the exponent on the *generic norm h* (degree r = 2). A "5/2" appears only if the base is rank-halved (h = D², exponent γ/rank per D-factor) or written per-Jordan-trace. **Either way the genus is 5 = n_C, never 7.** The corpus should state the *base* alongside the exponent and stop trading bare fractions (this is the same "pin the base, not just the number" discipline that caused the tangle).
