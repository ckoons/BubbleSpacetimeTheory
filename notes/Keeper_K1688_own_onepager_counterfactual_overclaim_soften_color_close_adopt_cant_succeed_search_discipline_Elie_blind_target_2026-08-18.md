But `3/13 = N_c/(N_c+2n_C)` is built from the **integer** `N_c = 3` — the short-root multiplicity, true regardless of realness. Complexifying `V₁₂` doesn't change that 3 is 3, so the counterfactual needs `θ_W` to depend on *realness*, and that step is asserted, not shown. Shared object, not shared property. The honest chain *is* available (realness → color is a discrete count → `N_c=3` as a multiplicity → `θ_W`), but the `realness → count` step must be **exhibited** (K1282), not asserted. **Fix (v0.4):** exhibit it (→ strongest sentence) or retreat to "shared ingredient."
