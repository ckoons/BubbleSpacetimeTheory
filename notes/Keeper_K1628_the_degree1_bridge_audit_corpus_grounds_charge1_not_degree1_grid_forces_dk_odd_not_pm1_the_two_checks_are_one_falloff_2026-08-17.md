# K1628 — the degree-1 bridge, audited: corpus grounds charge-1, not degree-1; the grid forces Δk-odd, not ±1; the two checks are one falloff

K1627 named the "weak current = degree-1 tensor operator on D_IV⁵" identification as the one new load-bearing gate — the ingredient on which Lyra's Wigner–Eckart CKM-skeleton rests. Recused from the derivation, I did the target-innocence audit on it (my lane): does the corpus already ground it, and does the framing hold?

## What the corpus grounds (the weak current is charge-1)
- **F311 (banked, structural):** the CKM is the up↔down mixing in charged-current (W) transitions; up vs down = the isospin T_3 = ±1/2 label; the charged current connects the T_3 = ±1/2 partners. So the weak current is a **charge-1 / Δm = ±1** operator. (Bonus, banked: CKM-left-handedness = SU(2)_R-breaking = matter chirality, one fact — not a separate input.)
- **F820 (banked):** charge→degree normalization **m = N_c·|Q|** fixes the SO(2)-charge label; with the **k+m-even fold (K1178)** this *is* the parity grid (down/leptons odd {1,3,5}, up/ν even {0,2,4}).

## The overclaim (degree-1 in k is NOT grounded)
Lyra's framing — "J_W is a **degree-1 tensor operator in the angular degree k**, so Wigner–Eckart forces a hard **Δk = ±1** selection rule" — is not in the corpus, and tracing it through the grounded pieces shows it overclaims. There are **two distinct labels**: the SO(2)-charge **m** (which the current changes, because up↔down changes charge) and the SO(5)-angular degree **k** (the shelf). The corpus grounds the current changing **m**, not **k**.

## The corrected mechanism (the grid forces Δk-ODD, not ±1)
Run the two grounded facts together:
- charge-1 current ⟹ **Δm = ±1**;
- physical modes stay on the **k+m-even grid** ⟹ an odd Δm needs an **odd Δk** to preserve k+m even.

So the grid forces **Δk = ODD (±1, ±3, ±5)** — not ±1 alone. **Δk = ±1 *dominance* is therefore not a selection rule; it is the coherent-state kernel falloff being monotone in Δk** — which is *exactly* Elie's blind test ("does the diagonal peak, not merely decay with gap"). The selection structure the corpus supplies is *parity* (odd gaps only), not *adjacency* (±1 only).

## The consequence for the count (Cal — this matters)
The two pre-registered pass/fail checks are **the same property read twice:**
- "the diagonal peaks" = the Δk=1 (shelf-aligned) entry beats the Δk=3 off-diagonal ⟸ monotone falloff in Δk;
- "V_ub (Δk=5) is uniquely smallest" = the largest odd gap is most-suppressed ⟸ monotone falloff in Δk.

Both are the single statement *"the coherent-state overlap falls off monotonically in Δk."* So they are **one test, not two independent confirmations** (consistency web, not independent votes). If the kernel is monotone in Δk, *both* pass together; if not, both fail. Elie's fire has **one** real structural degree of freedom here, and Cal should count it once.

## The honest split, revised
- **FORCED / target-innocent (grounded):** (1) mixing = cross-parity ⟨even|odd⟩ overlap; (2) the nonzero pattern is **Δk-odd** (from charge-1 F311/F820 + k+m-even grid K1178); (3) V_ub = the largest odd gap (Δk=5), hence most-suppressed **iff** the falloff is monotone.
- **THE BLIND TEST (Elie's fire, one DOF):** the coherent-state kernel is **monotone in Δk** — which delivers diagonal-dominance and V_ub-smallest together.
- **REVISED PIN for Lyra (this is the de-risk):** you do **not** need to pin "the weak current is degree-1 in k" (unsupported, and it would smuggle adjacency). Pin the two facts the corpus already gives — **charge-1/Δm=±1 (F311/F820)** and the **k+m-even grid (K1178)** — which together force **Δk-odd for free**. The ±1-dominance is Elie's kernel result, not a selection rule to assert. This keeps the ingredient honest and moves the load onto the blind test, where it belongs.
