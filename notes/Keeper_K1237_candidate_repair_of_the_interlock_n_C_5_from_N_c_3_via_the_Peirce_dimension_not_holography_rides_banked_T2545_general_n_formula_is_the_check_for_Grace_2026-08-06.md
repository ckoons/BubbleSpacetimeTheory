# K1237 — candidate repair of the interlock: n_C=5 from N_c=3 via the Peirce dimension, not holography

Cal broke the holography route to n_C=5 (K1236 — the SO(4,2)→SO(5,2) +1 was smuggled, and T2113 is Identified-pending). So I worked the crux for a *different* route, and there's one that rides a **banked** anchor.

## The repair
T2545 (banked, Cal-verified) says: the off-diagonal Peirce component **V₁₂ of the D_IV⁵ spin factor has dim = n_C − 2 = 3 = N_c**, and it IS the irreducible color triplet = the 3 spatial directions. Read as a **forcing** (reverse direction), with the general-n formula dim V₁₂(D_IV^n) = n − 2:

**N_c colors = dim V₁₂ = n − 2 ⟹ n = N_c + 2 ⟹ for N_c = 3, n = 5 = n_C.**

So **n_C = 5 is a consequence of N_c = 3 — via the Peirce structure, never touching holography.**

## Why this is better than the route Cal broke
- **Rides banked T2545**, not the Identified-pending T2113.
- **Never invokes holography** — so it sidesteps Cal's off-by-one (the SO(4,2)→SO(5,2) group-lift standard holography can't provide) entirely.
- **T2545 does double duty:** the same banked theorem is *both* the vertical necessity row (V₁₂ → space) *and* the horizontal dimension-fixer (N_c=3 → n=5). One theorem, both legs. And it **closes Elie's rank-2 residual**: commitment + rank-2 + Lorentzian-conformal → the *family* Type IV_n; then N_c=3 = dim V₁₂ = n−2 → n=5 → **D_IV⁵**, the dimension.

## The one load-bearing check (routed to Grace — do NOT let me smuggle again)
The argument reverses T2545 using the **general-n** formula dim V₁₂(D_IV^n) = n − 2. T2545 as banked computed this *at n=5*. The repair needs it for **general n**.

**Grace's check:** is **dim V₁₂(D_IV^n) = n − 2** a general-n Jordan/Peirce identity for the Type IV_n spin factor, or specific to n=5? *(Honest flag: my recollection of the spin-factor Peirce count is uncertain — conventions differ (n−1 vs n−2). ## Honest scope (what it does and doesn't do)
It forces **n_C given N_c** — an integer-collapse (2 independent inputs → 1). It does **not** force N_c=3 (that stays an input — observed, or from a deeper "why SU(3)" argument). Per the honesty control (K1235), the claim is the **implication** N_c=3 ⟹ n_C=5, not "n_C forced from nothing." Still valuable: it removes n_C from the independent-parameter count.

## Relation to the crux (K1236)
K1236's crux was "why SO(5,2) not SO(4,2) = why recording forces one extra dimension" (the holography framing, open). This repair answers "why n=5" a *different* way — "the color triplet IS the (n−2)-dim Peirce component" (the Jordan framing, banked T2545). The two should be **consistency-checked**: the extra dimensions beyond the 3-color-triplet are the rank-2 Cartan = time + commitment — likely the same story, but that's a check, not a bank.
