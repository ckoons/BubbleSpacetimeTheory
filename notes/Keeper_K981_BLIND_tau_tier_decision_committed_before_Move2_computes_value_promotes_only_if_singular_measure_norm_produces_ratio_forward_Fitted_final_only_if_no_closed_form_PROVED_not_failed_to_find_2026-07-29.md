# K981 — Blind criteria for the tau tier, before Move 2 runs

Move 2 (K980) will compute the tau mass at its ℓ=0 boundary seat (singular Shilov-vertex measure), in standard-physics linear algebra. It returns one of two outcomes. **I commit the tier ruling BLIND now**, before Elie's number, so it can't be retrofitted.

## The two branches, pre-registered

**★ BRANCH A — value PROMOTES off Fitted.** Earned ONLY if:
- **A1.** The singular-measure norm on the ℓ=0 boundary projection **produces the tau ratio FORWARD** (m_τ/m_e, or m_τ/m_μ) — computed from the boundary-mode structure with **no peek** at 49·71, the (7/3)^{10/3} form, or the measured mass.
- **A2.** The forward number matches observation at a stated precision (report σ, not raw %).
- **A3.** The boundary-mode identification (which physicist object — domain-wall zero mode / limit-of-discrete-series / boundary-dominated eigenvalue) is target-innocent, not chosen because it lands the number.
- Result: tau value → **IDENTIFIED** (or Derived-conditional per the open-piece test if the mechanism is forced), superseding the retired 49·71/10-3 decompositions.

**★ BRANCH B — "Fitted DERIVED-and-final".** Earned ONLY if:
- **B1.** A **POSITIVE structural proof** that the ℓ=0 singular measure **cannot carry a closed-form mass** — e.g. the boundary orbit's measure is a delta/singular distribution whose relevant moment is provably not a finite algebraic combination of the integers {2,3,5,7,137}. A derivation that the form does not exist, cast as linear algebra on D_IV⁵.
- **B2.** The interior modes (μ, e) DO carry closed forms on the smooth measure (the contrast that makes B1 meaningful — boundary vs interior is the whole content).
- Result: tau value stays **FITTED**, but tagged **"Fitted (derived-final)"** — a positive, publishable statement (the heaviest lepton is the boundary mode; boundary modes have measure-set, not closed-form, masses; 49·71 is a numerical shadow).

## ★ THE KILL / GUARD (the one way this goes wrong)
**"Fitted derived-and-final" (Branch B) is NOT earned by failure to find a form.** "We tried the singular-measure norm and couldn't get a clean number" leaves the tau exactly where it is: **FITTED-open**, an honest lead, NOT "derived-final." Branch B requires a *positive* no-closed-form proof (B1), the same way "no 4th generation" required three positive routes, not "we didn't find a 4th." Absent B1, the outcome is neither A nor B — it's status quo (Fitted-open), and Move 2 continues.

Symmetric guard on A: A1's forward number must be **blind**; 49·71 reverse-fit onto the measure (finding a measure whose moment happens to be 3479) is FITTED wearing a Derived costume, not Branch A.

Keeper rules the tau tier on Move 2 against A1–A3 / B1–B2 verbatim; Cal audits (is the norm computed on the singular measure, forward and blind, or assumed/reverse-fit?). The number does not move these criteria when it lands.
