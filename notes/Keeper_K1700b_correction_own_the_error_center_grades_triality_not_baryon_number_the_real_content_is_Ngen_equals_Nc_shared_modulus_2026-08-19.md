# K1700b — correction: the center grades triality, not baryon number; the real content is N_gen = N_c

**I own this.** Grace and Cal caught a genuine same-name-different-object error in my *own* ruling — the sixth/seventh of the week, and this one bit the auditor.

## The error (verified)
K1700 said "BST baryon number = the ℤ₃ **center**-grading of color." Wrong. The color center Z(SU(3)) grades **triality** `t = (n_q − n_q̄) mod 3 = 3B mod 3`, which is **≡ 0 identically on every color singlet** — the proton has t=0, and t is conserved in *both* proton decay and the sphaleron. So the center-grading **does not** forbid proton decay. Baryon-number-mod-3 is a **different function** (proton: B mod 3 = 1). I fused a **grading operator** (triality) with a **counting constraint** (B mod N_c).

The exactly-conserved object forbidding proton decay is the **integer winding per channel** (K1700a). The mod-N_c is what survives multi-channel processes.
