# K1190 — The Ordered-Product Refinement Procedure (a "fit" is a diagnostic, not a knob)

Casey: *"We'll need to identify/fit parts of the ordered product when the scales mismatch or we're missing the proper object (matrix/vector/scalar) — show me how to refine the linear algebra."* Here's the method.

## The procedure — when a rung's value is wrong, classify the gap by its signature
- **Type 1 — SCALE MISMATCH.** Shape/structure right, magnitude off by a ~constant. *Signature:* the pattern matches, only the overall normalization is wrong. *Fix:* pin the scale to a **forced geometric quantity** (a derived normalization). → **Forced** (was Identified only for lack of the normalization).
- **Type 2 — WRONG/MISSING OBJECT.** A scalar used where a vector/matrix is needed. *Signature:* wrong in a **structured, per-rung** way (not a uniform constant). *Fix:* identify the **correct object** (e.g. the per-shell factor is a *vector* of geodesic distances, not a scalar α). → the fit **dissolves into forced structure** → **Forced**.
- **Type 3 — GENUINE INPUT.** No forced object supplies it after refinement. *Signature:* nothing in the geometry forces it. → honestly **Identified** (an input on the floor, like the neutrino ratio) — not a failure, an honest input.

**The discipline:** a "fit" is a *hypothesis that structure is missing*, not a license to tune. Search for the scale (Type 1) and the object (Type 2) **first**; accept an input (Type 3) only when nothing forced supplies it. This keeps the tier honest both ways — don't call a knob "forced," don't call missing-structure a "permanent fit."
