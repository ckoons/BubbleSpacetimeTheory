## The gate — the declaration must supply ALL of A–D before any derivation
**A — the reference class (what set the atlas quantifies over).**
- [ ] A1 — states EXACTLY which geometric objects of D_IV⁵ are catalogued (the inventory above is the candidate list; the declaration commits to a closed list, not "etc.").
- [ ] A2 — states the DOMAIN of the atlas: is it *only* D_IV⁵, or the type-IV family D_IV^n, or all bounded symmetric domains? (The internal-SM theorem needed all three rungs declared; the atlas must pick its rung.)
- [ ] A3 — no "the atlas" as a bare noun anywhere without its reference class attached.

**B — what "a reading" is (the fact↔operation map).**
- [ ] B1 — declares the fact-set F (which physical observables the atlas claims to organize) and the operation-set R (restrict / count / identify — the AC(0) triad the one-page confirmed), exactly as the reading calculus did for the SM.
- [ ] B2 — every atlas entry is "one operation at one address"; the declaration says what an ADDRESS is (a K-type? a boundary stratum? a Peirce block?) — ONE definition, pinned.
- [ ] B3 — states the FORCED-vs-MEASURED tier discipline: each entry carries D/PD/I/C/S, and "forced by the geometry" vs "one measured input (the ruler)" is marked per entry (the ruler is CLOSED — one input, K1727/T2569; the declaration cites this, does not reopen it).

**C — the descent, declared separately (do NOT fold into the atlas).**
- [ ] C1 — the KK→ruler descent names WHICH reduction: KK on WHICH circle (the SO(2) center? the time circle?), to WHICH 4D (the (3,1) foliation, K1513/K1522). "The descent" as a bare noun is the same defect as "the atlas."
- [ ] C2 — states that the ruler is ALREADY closed (one input; neither scale nor shape forced, K1727/T2569) — the descent organizes the KK mechanism, it does NOT re-derive a forced ruler. Any "the descent forces the scale" claim is DEAD on arrival (dimensional-bar theorem).

**D — the Kostant-Dirac region (#124), scoped to what's proved.**
- [ ] D1 — cites T2562 as the anchor (the operator is confirmed self-adjoint, discrete, governs the quark ladder) and asks the SCOPED question — "which phenomena does D govern" — as an enumeration over the atlas's declared fact-set, NOT as an open-ended "what does Dirac do."
- [ ] D2 — the VALUE 6.25 stays convention-pinned (Cal §477), separate from the operator credential; the declaration does not relitigate it.
