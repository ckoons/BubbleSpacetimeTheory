- **H normalisation**:
  - `VISUAL_TRANSCRIPTIONS.txt:55-57`: "positive energy P⁰ ≥ 0 implies that also H ≥ 0, where H = ½(P⁰ + K⁰) is the "conformal Hamiltonian", K⁰ a generator of special conformal transformations."
  - The same formula appears as the Lemma 1 statement (`VISUAL_TRANSCRIPTIONS.txt:84-85`).
- **Sign of K** (`VISUAL_TRANSCRIPTIONS.txt:63-71`, typed p.7, eq. 2.21): K is the generator of the lower-triangular subgroup "N: n = (𝟙 0 ; i ñ 𝟙)". P is the generator of "X: x = (𝟙 i x̰ ; 0 𝟙)". Explicitly R = exp 2πiH₂" (`VISUAL_TRANSCRIPTIONS.txt:77-78`) fixes the relative sign: K⁰ is unitarily conjugate to P⁰, so K⁰ ≥ 0 whenever P⁰ ≥ 0.

### Pins

- **Unitarity bounds, verbatim** (typed p.1; `VISUAL_TRANSCRIPTIONS.txt:47-54`; the OCR at `mack_desy75-050_preprint_inspire_OCR.txt:43-52` is garbled):
  > "There are 5 classes of representations. They differ in their Poincaré content [m, s], m = mass, s = spin resp. helicity as follows:
  > (1) trivial 1-dimensional representation d = j₁ = j₂ = 0 .
  > (2) j₁ ≠ 0, j₂ ≠ 0, d > j₁+j₂+2 contains m > 0, s = |j₁−j₂| ... j₁+j₂ . (integer steps)
  > (3) j₁j₂ = 0, d > j₁+j₂+1 contains m > 0, s = j₁+j₂ .
  > (4) j₁ ≠ 0, j₂ ≠ 0, d = j₁+j₂+2 contains m > 0, s = j₁+j₂ .
  > (5) j₁j₂ = 0, d = j₁+j₂+1 contains m = 0, helicity j₁−j₂ ."
- **Scalar case (read off, not a separate sentence in the paper).** Take j₁ = j₂ = 0. Class (1) gives d = 0 (trivial), class (3) gives d > 1, class (5) gives d = 1. So the scalar unitary set is {0} ∪ [1, ∞), i.e. d ≥ (4−2)/2 = 1 in 4D.

- **H ≥ 0** (Lemma 1, `VISUAL_TRANSCRIPTIONS.txt:81-85`):

### What groups and representations they treat

- **Part I is general.** "differential symmetry breaking operators for equivariant vector bundles over two homogeneous spaces" (`.txt:10-11`); "continuous symmetry breaking operators of Hermitian symmetric spaces are proved to be differential operators in the holomorphic setting" (`.txt:15-17`).
  - O(n+1,1) ⊃ O(n,1) appears in Part I only as a contrast (Remark 5.5, `.txt:1771-1775`): "for the pair (G, G′ ) = (O(n + 1, 1), O(n, 1)) there always exists a non-zero continuous G′ -equivariant map from the spherical principal series representations … however, non-zero G′ -equivariant differential operators exist if and only if ν − λ ∈ 2N [KS14]."
  - So **O(n+1,1) ⊃ O(n,1) is NOT their setting.** Their setting is the holomorphic one.
- **Part II lists six holomorphic geometries** (Table 1.1, `.txt:2256-2260`), including "(3) Qn C ↪ Qn+1 C", which is the SO(n,2) ↓ SO(n−1,2) case. Theorem A (`.txt:2273-2277`):
  > "(1) Any continuous G′ -homomorphism from O(X, Lλ ) to O(Y, W) is given by normal derivatives with respect to the equivariant embedding Y ↪ X if the embedding Y ↪ X is of type (4), (5) or (6) in Table 1.1. (2) None of normal derivatives of positive order is a G′ -homomorphism if the embedding Y ↪ X is of type (1), (2) and (3) in Table 1.1."
  - **Consequence for us:** for SO(n,2) ↓ SO(n−1,2), plain normal derivatives are NOT the intertwiners. The intertwiners are Gegenbauer-type.
- **Theorem B(3)** (`.txt:2318-2325`, the operator glyphs are garbled in the text layer):
  > "(3) For the symmetric pair (SO(n, 2), SO(n − 1, 2)) the differential operator C̃ᵃ^{λ−(n−1)/2}(−∆_{C^{n−1}}, ∂/∂zn) is an intertwining operator from O(X, Lλ ) to O(Y, Lλ+a ), for any λ ∈ Z and a ∈ N."
  - The operator is rendered from the displayed formula (the superscript "λ− (n−1)/2" is legible in the text layer). The same operator is eq. (6.6), Theorem 6.3, `.txt:3424-3432`.
- **Setting of Section 6** (`.txt:3350-3358`): "Let G be its identity component SOo(n, 2). Then the G-orbit through the base point … is identified with the Lie ball X … which is the bounded Hermitian symmetric domain of type IV in the É. Cartan classification. … The group G′ = SOo (n − 1, 2) acts on the subsymmetric domain Y ∶= X ∩ {zn = 0}. Then Y ≃ G′ /K ′ = SOo(n − 1, 2)/SO(n − 1) × SO(2) a subsymmetric space of X of complex codimension one."

### λ convention

- `.txt:3361`: "For λ ∈ Z we define a character of c(k) by tHo ↦ λt". Here Ho = E_{0,n+1} + E_{n+1,0} is the characteristic element. The multiplier is J(g⁻¹,z)^{−λ} (eq. 6.4). Complex λ is allowed on the universal cover G̃.
- **Unitary range** (Remark 6.4, `.txt:3445-3447`): "If λ ∈ R and λ > n − 1, then H2 (X, Lλ ) ∶= O(X, Lλ ) ∩ L2 (X, Lλ ) is a non-zero Hilbert space on which G̃ acts unitarily and irreducibly, giving a holomorphic discrete series".

- **Uniqueness** (Theorem 6.1, `.txt:3392-3397`): "Let n ≥ 3 … (i) HomG̃′ (O(X, Lλ ), O(Y, Lν )) ≠ {0}. (ii) dimC … = 1. (iii) ν − λ ∈ N."

Juhl [J09] in the setting S n−1 ↪ S n , with equivariant actions of the pair of groups SO(n, 1) ⊂ SO(n + 1, 1) … The F-method gives a conceptual explanation for the appearance of Gegenbauer polynomials in Theorem 6.3."

### Our case: SO(2,5) scalar weight λ restricted to SO(2,4)

JV's n + 1 = 5, n = 4, D_IV^5 ⊃ D_IV^4, scalar τ = (α, trivial).

1. **The paper does NOT state the scalar SO(2,5) ↓ SO(2,4) decomposition as a displayed formula.** It follows from Prop 2.5 plus the Section 3 composition-factor statement.
   - μ trivial restricts to trivial on SO(4), so l = 1, and the factors are 𝒪^f(α+i, trivial, 4), i = 0, 1, 2, …, pairwise non-isomorphic (block K).
   - For α > 3/2, α ∈ I ∩ P (block L). Prop 2.5 then upgrades the filtration to a Hilbert direct sum. Result, as a DERIVED reading, not a quote:

     H(α; 5)|_{SO₀(2,4)} = ⊕_{k≥0} H(α+k; 4), multiplicity one.

   - INFERENCE used: p⁺/p₁⁺ is one-dimensional (complex codimension one) with trivial SO(4) action. This is consistent with K12, where each i occurs once.
2. **At the Wallach point α = 3/2 the claim in the brief FAILS as stated.** Prop 3.2 gives exactly two summands, T(3/2; 4) ⊕ T(5/2; 4), not ⊕_{k≥0}. At α = 0 (trivial) there is one summand.
   - So "⊕_{k≥0} with multiplicity one" should be stated for **λ > 3/2**, not for the whole Wallach set.
3. **Integrality.** JV set up T_α for α ∈ ℤ on the linear group (block L1-L2). Real non-integer λ ∈ (3/2, ∞) needs the universal cover; JV do not write it.
   - Kobayashi–Pevzner (`arxiv_1812.09733.txt:1611-1623`) do cover real λ on the cover: "For λ ∈ C, we define a character of c(k) by tH0 ↦ λt, which lifts to a character Cλ of K̃ … This Hilbert space is nonzero if and only if λ > n − 1".
   - They state the branching law for **λ > n − 1 (= 4 for n = 5)** (`.txt:1791-1796`):
     > "decomposes the restriction πλ^(n)|G̃′ into a multiplicity-free direct Hilbert sum of irreducible representations of the subgroup G̃′, see [13, Thm. 8.3]: (3.11) πλ^(n)|G̃′ ≃ Σ⊕_{ℓ∈N} πλ+ℓ^(n−1)."
   - Labriet (5.8) states the same for λ ∈ N, λ > n−1 (item 4).
   - **Gap:** real non-integer λ ∈ (3/2, 4]. No file here quotes it. The expected source is T. Kobayashi, "Multiplicity-free theorems of the restrictions of unitary highest weight modules…", Progr. Math. 255 (2008) 45–109, Thm 8.3. **PIN OWED.** One caveat is flagged in KP: "The subgroup G̃′ is simply connected if n ≠ 4" (`arxiv_1812.09733.txt:1666`), so for n = 5 the subgroup G̃′ ⊂ SO₀(2,5)~ is simply connected.
