# R16 PINS (draft): massless ladders as subquotients of the 4D conformal degenerate principal series

## 0. Verdict (short)

1. **Helicity 0 (the minimal rep, Δ = 1).** It is the unique irreducible subrepresentation of the scalar light-cone (conformal-parabolic) degenerate principal series of O(p,q), p+q even, at **λ = −1** in Kobayashi–Ørsted's normalization, where the unitary axis is λ ∈ iℝ (P2, P3). It is the quotient at λ = +1. In Howe–Tan's unnormalized homogeneity this is a = −(p+q−4)/2 = **−1** for (4,2). The unitary-axis centre is at a = −2 (P1). For U(2,2) with the Siegel parabolic it shows up at **s = ±1**, σ odd (ARITHMETIC on Lee–Loke (24), P5).
2. **At ν = 0 (λ = 0, a = −2, "Δ = 2"), no ladder occurs in the scalar family.** The reducible summand at λ = 0 splits as a direct sum of two unitary irreducibles, π₋,₀ ⊕ π₊,₀ (K–Ø II (5.5.7), P3; Howe–Tan case (iv), P1). The other summand is irreducible. None of these pieces is the minimal/ladder rep. By K-type computation (INFERENCE), the positive-energy piece is the scalar Δ = 2 lowest-weight UIR, which is not a ladder.
3. **Helicity ±1/2 and ±1 ladders cannot be subquotients of any scalar-character degenerate principal series of the conformal/Siegel parabolic.** Every K-type in those families has j₁ = j₂, while a helicity-h ladder has lowest K-type (0,|h|) or (|h|,0). This is an exhibited K-type obstruction. It is INFERENCE, assembled from pinned K-type formulas (P2, P4, P7).
4. **They are subquotients of the "elementary representations" (generalized principal series).** These are induced from the same parabolic P₂ = M₂A₂N₂ (M₂ = Lorentz), but with a finite-dimensional non-unitary Lorentz rep (j₁, j₂). Dobrev (P6):
   - helicity ±1/2 sits at d = 3/2 (c = −1/2);
   - **helicity ±1 sits at d = 2, i.e. c = 0**, the Knapp–Stein self-dual centre of the A₂-parameter;
   - helicity 0 sits at d = 1 (c = −1).
   
   Because the inducing Lorentz rep (1,0) is finite-dimensional and non-unitary (Dobrev states this, P6), c = 0 in that family is **not** a unitary axis. It is not the edge of a tempered continuum (INFERENCE).

- Parabolic: "Let P1 ⊆ O(p, q) be the stabilizer of the line Rw1 through w1 . Then P1 is a parabolic subgroup" (`:183`). This is the light-cone/conformal maximal parabolic.
- Parameter: "S a (X 0 ) … of smooth functions on X 0 homogeneous of degree a under dilations by positive scalars" (`:245`). These are identified with Ind from ψ_a^± "(Here we are using unnormalized induction.)" (`:284`).
- Unitary axis: "Lemma 3.1. When Re a = −[(p + q)/2] + 1, that is, for a = −[(p + q)/2] + 1 + is, s ∈ R, the Hermitian inner product which equals the standard inner product on each K-type, is O(p, q) invariant." (`:1294`). The shifted parameter is "ã = a + (p+q)/2 − 1" (`:1330-1333`, stacked fraction), and "We will call the set of a with Re ã = 0 the unitary axis" (`:1344`).
- For (p,q) = (4,2) [ARITHMETIC]: the unitary axis is Re a = −2 and ã = a + 2. The unitary-axis centre is a = −2.

## 4. Is any ladder a subquotient at the ν = 0 (unitary-axis centre) point?

**Scalar (one-dimensional character) degenerate principal series of the conformal parabolic. Answer: No.**
- O(4,2) at λ = 0: pinned by K–Ø II (5.5.7). One parity gives π₋,₀ ⊕ π₊,₀, a direct sum of unitary irreducibles. The minimal rep is not among them. Its K-types n = m+1 have the wrong parity for this summand (ARITHMETIC), and ̟ occurs at λ = ±1 by (5.5.5)/(5.5.6).
- Howe–Tan agree. At a = −(p+q)/2 + 1 = −2 the reducible summand is "the direct sum of two irreducible modules" and "the only value of a that gives a decomposable module" (P1(iv)). The single-line (ladder) piece occurs at ã = ±1, not at ã = 0 (P1 Remark (b)).
- On SO₀(4,2)/SU(2,2): π₋,₀ (no n = 0 K-types) splits into holomorphic ⊕ antiholomorphic (HT `:1229-1238`). The positive-energy half is the scalar Δ = 2 lowest-weight UIR, and it is not a ladder (INFERENCE from K-types, `check_r16_ktypes.out`).
- Cross-check: the Lee–Loke U(2,2) Siegel count at s = 0 (three direct summands) matches K–Ø plus the HT splitting count (π₊,₀ + two halves of π₋,₀ = 3). At s = −1 it gives 5, matching ̟ (2 halves) + π₋,₁ (2 halves) + π₊,₁ = 5. This supports the INFERENCE s ↔ λ. It is a count match, not a proof.

**Helicity ±½ and ±1. Not in the scalar family at any parameter.**
- The obstruction: every K-type there has SU(2)×SU(2) type (j,j). For O(4,2), H^m(ℝ⁴) is (m/2, m/2) (INFERENCE, standard). For U(2,2), V_λ = τ^λ ⊠ τ^{λ*+σ1} has equal SU(2) spins (ARITHMETIC on `:309`).
- A helicity-h ladder with h ≠ 0 contains K-type (0,|h|) or (|h|,0) (P7). So it cannot be a subquotient.
- This is an exhibited obstruction on one implication (K-type containment). It is not a contradiction argument.

**Generalized principal series from the same parabolic with a Lorentz-spin inducing rep (Dobrev ERs).**
- Helicity ±1 is realized at **d = 2, c = 0**: the Knapp–Stein self-dual point, since pairs have d + d′ = 4 (`:662-665`).
- Helicity ±½ is at c = −½. Helicity 0 is at c = −1. Helicity |h| ≥ 1 is at c = |h| − 1 in general.
- So the answer to "does any ladder occur at ν = 0?" is **yes, helicity ±1 (Maxwell), but only in the non-unitary finite-dimensional-M-rep family**.
- There c = 0 is not a unitary axis. Dobrev himself flags the inducing µ as "finite-dimensional (nonunitary)" (`:138`). So [1,0; 2] is not a tempered (unitary principal series) representation, and c = 0 there is not "the edge of the tempered continuum" (INFERENCE). The unitary principal series from P₂ would need unitary (infinite-dimensional) reps of M₂ = SL(2,ℂ).
- Honest form: *at the A-parameter centre, the only massless ladder that occurs as a subquotient of a conformal-parabolic induced representation is helicity ±1, and only when the inducing Lorentz rep is the non-unitary (1,0)/(0,1); in the scalar (tempered-axis) family, nothing ladder-like occurs at ν = 0.*
